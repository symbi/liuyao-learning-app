2. **外部项目用于比较**：用于发现算法、数据结构、测试案例和不同流派；不能仅因开源项目这样实现，就认定规则正确。
3. **来源分层**：课程明确、外部参考、推断/候选、有分歧、程序验证通过，分别标注。
4. **先记录再采用**：未核对规则、许可证、测试和日期口径前，不复制代码、不加入正式计算链。
5. **原始/整理分仓**：本文件及整理后的摘要放在 Public 的 `liuyao-learning-app`；课程原始录音、ASR 转录和未校订材料放在 Private 的 `liuyao-learning-raw`。

### 历法实施原则

- 当前页面以日本当地日期 `Asia/Tokyo` 为输入。日期选择、历史记录、宿值计算都必须使用同一个明确日期。
- 历法库通过 adapter 接入；业务代码不散落第三方 API 调用。
- 保存日期结果时记录算法 ID、版本、时区和计算口径。
- 至少用独立来源核对节气边界、日柱和连续日期，不只比较两个同源移植项目。

## 3. 二十八宿：天区体系、四象分组与“值日宿”

### 3.1 二十八宿的天文含义

二十八宿不是凭空编出的 28 个日名。它们源自中国古代天文学，是沿天球赤道/黄道附近选定的星区、星官参照体系，用来描述日月五星相对于恒星背景的位置。各宿的实际宿度并不相等。

因此需要区分两种显示/计算：

- **值日二十八宿（本项目拟采用）**：按某套黄历约定，每个公历日轮值一宿，28 天循环。它回答“今天按这套值日表轮到哪一宿”。
- **天体实际所在宿**：需要指定时刻、天体（例如月亮）的位置，并依据二十八宿的天文边界/距度判断。它不等于每天固定前进一宿；月亮运行速度和宿度不均匀都会影响结果。

本项目用户想要的是第一种“今天值哪一宿”，不是天文观测软件。UI 应明确写“值日宿”或“今日值宿”，避免暗示这是月亮此刻真实所在的星区。

参考：
- 故宫博物院“四神将”：https://www.dpm.org.cn/lemmas/239601.html
- 二十八宿交互天区与宿度示意：https://www.yiwen.life/zh-CN/charts/ershiba-xiu
- 二十八宿真实天区/距星资料：https://www.taiyi.me/llsz/ersb
- 二十八宿与四象概述：https://www.zzrvtc.edu.cn/dqgcx/2019/0513/c1059a53816/page.htm

### 3.3 值日轮值算法（候选实现）

在 `OPN48/cnlunar` 的 `cnlunar/lunar.py` 中：

```python
apart = target_date - datetime(2019, 1, 17)
today28Star = the28StarsList[apart.days % 28]
```

`cnlunar/config.py` 中的列表顺序为：

`角木蛟、亢金龙、氐土貉、房日兔、心月狐、尾火虎、箕水豹、斗木獬、牛金牛、女土蝠、虚日鼠、危月燕、室火猪、壁水貐、奎木狼、娄金狗、胃土雉、昴日鸡、毕月乌、觜火猴、参水猿、井木犴、鬼金羊、柳土獐、星日马、张月鹿、翼火蛇、轸水蚓`。

注意：
- 2019-01-17 在此实现中映射到角木蛟（数组第 1 项）。
- 本项目必须把该锚点、序列、算法 ID 和实现版本作为数据记录；不能只存“宿名”。
- 这是一个开源实现的明确约定，不代表所有通书/历派唯一通用。正式采用前需再用独立黄历/通书日期表核对多个跨年日期。
- 另有按儒略日和不等宿度推算“天体所在宿”的实现；那是另一种计算口径，不应与日轮值算法混用。

### 3.4 当前日期核对样例

按上述 cnlunar 轮值算法，公历 **2026-11-09**：

- 与 2019-01-17 相差 2853 天。
- `2853 mod 28 = 25`，数组从 0 开始索引，因此取第 26 项：**张月鹿（张宿）**。
- 所属：**南方朱雀**。
- 本项目 UI 应显示南方朱雀七宿：井、鬼、柳、星、张、翼、轸，并突出“张月鹿”。

该样例是算法计算结果，不等于对实际月亮天区位置的判断。

当前状态：**外部候选 / 待古籍或通书核验**。

原因：
1. 不同通书、天星择日派和黄历产品的宿宜忌可能不同。
2. 开源字典本身没有充分给出每一条宜忌对应的古籍版本、卷次、页码或校勘依据。
3. 不能把该表与建除十二神宜忌、当天综合黄历宜忌直接合并。
4. 第三方数据里有安葬、造葬等古代事项；本项目 UI 应遵循现代化原则，未经用户确认不显示这些不适用事项，但研究记录保留原始词目与出处。

- 宜：嫁娶、开市、出行、建造
- 忌：安葬
- 描述：张宿为吉星，利嫁娶开市出行

**这组内容只能标为“二十八宿本宿宜忌（候选参考）”，不能标成当天综合宜忌，也不能作为最终择日结论。**
