## 1. 《易冒·卷五·年运章第四十七》

- [中华典藏网：《易冒》卷五·年运章第四十七](https://www.diancangwang.cn/xuanxuewushu/a83f79a2e823/241b1554f141.html)
- [中国哲学书电子化计划：《易冒》卷五相关章节](https://ctext.org/wiki.pl?chapter=966762&if=gb&remap=gb)
- [识典古籍：《易冒》卷五全文](https://www.shidianguji.com/book/NA06416/chapter/1m7f91wiutn38)

相关内容摘要：

1. 年运占问需要先分清时间远近，书中说可占三年或当年，均以世爻为本。
2. 书中把世爻旺衰、空破、动静、日月生扶列为年度状态的重要因素；并提出世爻旺、官鬼静等为较安稳的条件。
3. 书中将世空解释为“有谋而虚望”，世破解释为可能无故受灾，并讨论动则劳、静则逸、冲散等情况。
4. 书中按六亲给出求名、问利、子孙、贵人等不同方向的取象，并提出年运应先避凶、再趋吉。
5. 书中亦提到卦象上的提醒需结合官鬼发动等条件，不应只凭卦名孤立断事。

**与课程的关系：**本课同样以世爻作为年度判断的主要起点，并继续观察财、子孙、父母、官鬼、兄弟等爻。古籍对世空、反吟伏吟、官鬼等给出更明确的断语，但本课转录没有足够清晰地确认老师采用了这些完整规则。因此，仅作对照，不当作课程原话或自动判定规范。

## 2. 《易冒·卷五·身命章第四十六》

- [常先易古籍书库：《易冒·身命章第四十六》](https://mediumslateblue-tarsier-426352.hostingersite.com/guji/yimao/wz-text-20260928/chapter-046/)

该章讨论平生/终身层面的问法，同时提到“自占凭世，六亲凭用”等观点，可帮助区分终身趋势、年度年运与某一具体六亲事项。

**与课程的关系：**本课主要讨论某一年的年运，不应自动解释成终身命运判断。若要使用终身卦或长期趋势，应单独明确时间范围与方法来源。

## 3. 现代年运卦讨论：背景与具体事项分开

- [乾坤网：流年运势，六爻如何分析“年运卦”？（2025-01-16）](https://www.d02.cn/html/suanming/zhouyisuanming/liuyaozhishi/2025/0116/127654.html)

该文提出年运分析应考虑卦主现实背景、动爻线索；若求测者已明确询问某一年的具体财运或感情事项，则应按对应事项取用神。

**与课程的关系：**此为现代作者的个人总结，不是古籍原文，也不是老师课堂依据。它与本课“年度概览和具体专项问题需要区分”的方向有相似处，但不作为课程规则的权威来源。

## 4. 终身卦与流年卦的区分：现代答疑材料

- [《李洪成六爻答疑500问》第 358 题及相关问答](https://bbscn-ly.luckerhome.com/article/webTopicPage/6/6003514.html)

该答疑将终身卦表述为以世爻为论事中心，再按相关用神与各年旺衰判断不同年份。该材料可用来提醒读者，终身卦、年度年运和具体事项并非同一种时间尺度。

**注意：**这是现代答疑材料，并非所有流派共同承认的唯一方法，也不能替代老师本课对年运时间范围的进一步说明。

## 5. 项目记录原则

- 课程讲法、古籍原文和现代作者总结分别登记。
- 年运卦的世爻主轴不能自动推导为某一套终身卦算法。
- “世空”“官鬼发动”“反吟伏吟”等外部古籍规则，只有在课程原文或用户确认后才可并入课程规则。
- 年度财务、工作、健康、房产等分项提示均需回到具体问事，不能从一条六亲旺衰直接输出确定结论。
