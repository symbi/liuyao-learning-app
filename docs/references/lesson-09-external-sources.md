# 第九课外部参考：用神、原神、忌神、仇神与旬空

> 外部资料用于对照传统术语，不代表老师课堂原话，也不自动成为本课程规则。尤其“原神/仇神”的使用在不同注家之间存在分歧；本项目保留各自观点。

## 1. 《卜筮正宗》用神分类与关系取用

- [《卜筮正宗》卷三·十八论用神（识典古籍）](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpdr8oqhb)
  - “分类定例”列出父母、官鬼、兄弟、妻财、子孙五类用神的常见事项。
  - “世应论用神”区分世爻与应爻，并以世应相生相合、相克相冲说明双方关系。
  - “用神问答”讨论代占时必须说明求测者与目标人物的关系。
  - 对姻亲关系，该书列有“姊妹丈夫”等具体分类，显示亲属取用并非只看对象性别，而需按关系链定位。
- [《卜筮正宗》用神六论（时者典籍，篇选）](https://dao.time.actor/bushi-zhengzong-pianxuan/yongshen)
  - 汇总用神分类、世应与亲属关系问答，可作为检索对照。
  
**与课程对照：**本课老师同样强调先确定具体问题与代占关系。课堂 ASR 对姐夫、妹夫、嫂子等例子的问答识别不可靠；不能用外部分类静默替老师补完课程答案。

## 2. 原神、忌神、仇神与“贪生忘克”

- [《卜筮正宗》卷三·十八论用神（识典古籍）](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpdr8oqhb)：原文以“生用神之爻”为原神、“克用神之爻”为忌神；仇神为克制原神、生扶忌神者；也记载忌神与原神之间出现特定生扶关系时的“贪生忘克”说法。
- [刘恒注解《卜筮正宗》二十一：原神忌神论（北京风水学会）](https://fengshui678.com/show/1229.html)：页面第 80–89 行列出《卜筮正宗》原文，包括原神、忌神、仇神的定义与“仇神发动，则原神被伤、忌神倍力”的论述。
- 同一页面第 90 行的刘恒注解又提出另一种解释：认为原神与仇神的概念“无意义”，主张先看用爻旺弱及其他爻的作用。这是注解者对经典原文的不同理论判断，不是原文的同义改写。
- [《卜筮正宗》十八论（易矩阵）](https://yimatrix.com/ko/academy/books/22/chapter/3966)：提供原忌仇神论相关文本，可作为另一份在线录文对照。

**项目处理原则：**
1. 本课程明确教授原神、忌神、仇神，因此课程笔记先忠实记录老师的体系。
2. 经典原文与后世注解必须分开标注。
3. 程序不能只凭“某六亲=原神/忌神”硬编码；应由当前用神的五行关系推导。
4. “贪生忘克”须保留原始关系链及适用条件，不简化成“凡有相生就不相克”或“所有连续相生必吉”。

## 3. 旬空与出空

- [青岚六爻基础：旬空](https://www.zhaosir.online/Books/BookChapterDetail.aspx?did=694)：说明旬空以起卦日干支确定，并区分真空、假空；旺相、发动或得其他爻生扶的旬空爻，仍可能待出旬、填实或冲起后发挥作用。
- [《卜筮正宗》卷三·十八论用神（识典古籍）](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpdr8oqhb)：也把旬空、动静、生克、日辰月建及出旬值日放在同一分析框架中。

**与课程对照：**本课以用神旬空、原神发动生扶为例，讨论出空后的作用。课堂例盘缺少准确干支与具体时点，不能直接把外部资料里的真空/假空规则全部算成本课已确认内容。

## 4. 伏神

- [《卜筮正宗》卷三·十八论用神（识典古籍）](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpdr8oqhb)：“伏神正传”讨论用神不现时按本宫首卦寻找伏神的传统方法，并区分用神不现、旬空、月破等情况。

**与课程对照：**伏神基础在前课已有涉及；本课关于“伏神与旬空能否同时出现”的问答 ASR 失真，本文不据外部资料替老师补出答案。

## 5. 世应爻与卦级关系

- [《卜筮正宗》卷三·十八论用神（识典古籍）](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpdr8oqhb)：将世爻解释为自己、应爻解释为他人，并分别讨论世应相生相合、相克相冲。

**项目处理原则：**课程要求比较实际世爻与应爻，不能把上卦/下卦直接替代世应。卦级六冲/六合和两条具体爻之间的五行关系应分字段保存。

## 6. 课程与外部资料边界

- 课程观点优先记录在课程笔记与规则卡片中。
- 古籍原文、后世注释、现代网络整理应标明不同来源层次。
- 来源之间发生分歧时保留分歧，不静默合并。
- 所有案例若缺少完整卦盘、起卦时间或问事背景，只能作为讨论线索，不能伪装成可复算测试。
- 本类资料属于传统术数文献整理，不构成现实医疗、投资、法律或其他重大决策依据。
