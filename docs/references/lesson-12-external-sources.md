## 1. 《卜筮正宗》：旺相休囚论、合中带克论、合处逢冲/冲中逢合论

- 在线文本：[《卜筮正宗》十八论（第十三至第十五）](https://www.quanxue.cn/qt_mingxiang/boshi/boshi30.html)
- 另一个可交叉查看的文本：[《卜筮正宗》卷三相关章节](https://www.shidianguji.com/book/AMNL0060/chapter/1ma05ao3rvqqy)

相关内容摘要：

1. **旺相休囚论**：列出春木旺火相、夏火旺土相、秋金旺水相、冬水旺木相、四季之月土旺金相，并指出旺相爻即使暂时得令，若受日辰或动爻克制，过时仍可能受其影响；休囚爻若得到日辰或动爻生扶，也可能待时而用。
2. **合中带克论**：以子爻变丑、戌爻变卯为例，说明六合与五行相克可同时存在。该篇强调需要看旺衰、月日生扶和动爻作用：一方有力时可偏向合论，受克一方休囚而克方有力时可偏向克论。
3. **合处逢冲、冲中逢合论**：将六合变六冲、六冲变六合及日月/动爻的冲合纳入分析，强调关系变化的先后过程。

与课程的关系：本课讲解的主线与这三论相当接近，尤其是“不能只看合，要比较双方力量”。但课堂中子月 A/B/C 练习的选项和完整卦盘不清楚，不能据外部版本替课堂恢复答案。

## 2. 旺衰表存在不同整理口径

- [《增注周易神应六亲百章海底眼前集》相关段落](https://www.shidianguji.com/zh/mid-page/7592368347519909898)
- [《易学四同别录·浑天六位图》相关段落](https://www.shidianguji.com/zh/book/7398438943139561524/chapter/1kbmc0gwj4mxn)

观察到的差异：

- 《增注周易神应六亲百章海底眼前集》给出春木旺火相、夏火旺土相、秋金旺水相、冬水旺木相等说明，并出现“六月金亦旺”的特殊表述。
- 《易学四同别录》采用“当生者旺、所生者相、生我者休、克我者囚、我克者死”的分类，并对夏季土专旺、其他三季土的状态另作说明；这与常见的“四季土旺”简化表并不完全相同。

因此，旺相休囚的季节表不能被假设为所有文献、所有派别都完全一致。当前课程记录先以老师课堂明确讲出的四季对应为准；丑月金的具体力量问题仍待课堂例盘复核。

## 3. 《增删卜易》：六冲章

- [《增删卜易·六冲章第二十》](https://www.shidianguji.com/book/XYXZSBY/chapter/1lzxsnhrjf0nu)

该章列出六冲的不同来源，并说明用神旺衰会影响冲的结果。对六合卦变六冲的描述强调“有始而无终”的可能；不能只因出现六冲，就对所有占问一概判断为凶。

## 4. 《增删卜易》：反吟、伏吟

- [《增删卜易》全文中的“反吟伏吟”章节](https://zh.wikisource.org/zh-hans/增删卜易)

可作为后续专门课程的预习资料。该章节分别讨论卦的反吟、爻的反吟及卦的伏吟；概念涉及本卦与变卦、内外卦及爻支变化。当前第十二课只作预告，暂不把该书的定义直接当作老师本课的完整讲义。

## 5. 明动与暗动对变卦的影响：现代答疑资料

- [《李洪成六爻答疑500问》相关问答](https://wap.china197.com/h-nd-63.html)

该问答讨论“暗动爻是否也列变卦”：其解释区分暗动爻所在内卦/外卦是否另有明动爻。它可作为复核第十二课最后一个课堂提问的线索，但并非老师本课的权威答案。第十一课与第十二课有关暗动的表达，仍应优先等候更清晰的课堂音频、板书或完整例盘。

## 6. 项目记录原则

- 古籍原文、现代注解、课程说法分开登记。

- 例题缺少完整卦盘时，不以外部资料补造输入和预期结果。
