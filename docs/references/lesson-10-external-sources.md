# 第十课外部参考：月建、日辰、月破、三合与伏神

> 本页外部资料仅用于术语对照和规则差异记录，不代表老师课堂原话。课程转录的 ASR 噪声较明显；本课主要讲月建，日辰和三合完整算法并未全部讲完。

## 1. 月建/月令与四时旺衰

- [《增删卜易·四时旺相章》（识典古籍）](https://www.shidianguji.com/book/XYXZSBY/chapter/1lzxsn553lws2)：按十二月列出月建及五行旺相、休囚的季节关系。
- [《增删卜易·月将章第十六》（维基文库）](https://zh.wikisource.org/zh-hant/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93/16)：将月建/月令视为一月当权之令，说明它能生扶、冲克、刑破爻，也可作用于动变及飞伏。
- [《卜筮正宗》卷十三（识典古籍）](https://www.shidianguji.com/zh/book/AMNL0060/chapter/1ma05b8mpspbf)：包含旬空、月破等基础规则的专题文字。

**对课程的帮助：** 外部资料支持“月份是季节性旺衰背景”的基础理解。但本课只重点强调月令作用，并未完整教完四时旺衰与全部应用规则，不能将外部表格直接当成已确认程序逻辑。

## 2. 月破与“逢破不一定永久无用”

- [《增删卜易·月将章第十六》（维基文库）](https://zh.wikisource.org/zh-hant/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93/16)：说明月建冲爻为月破；同章后文又讨论用神旺相、受克、等待冲去伤爻之日等情况。
- [《增删卜易·月破章》（太乙书局）](https://www.taiyi.me/book/index?id=214254283821125)：讨论用神月破、出月、实破日、逢合之日及静爻/动爻条件。
- [《卜筮正宗》卷十五（识典古籍）](https://www.shidianguji.com/zh/book/HY0057/chapter/1lpdfpvhjvkf7)：含月破用神、出破、填实及具体占例。

**重要区别：** 不同古籍章节或注家的措辞并不完全相同。本课老师强调要结合爻的旺衰、动变和日月，不要只看到月破就判死；但这不等于月破一定能救，也不等于逢出月就必然转吉。需按用神与全卦条件分别分析。

## 3. 日辰与月建的区别

- [《增删卜易·日辰章第十七》（《增删卜易》维基文库总目/卷页）](https://zh.wikisource.org/zh-hant/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93)：说明日辰对爻的生克冲合、旺衰、暗动、日破、冲空和冲合等影响。
- [《增删卜易·月将章第十六》](https://zh.wikisource.org/zh-hant/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93/16)：与日辰章并列，可对照月令当令与日辰作用的不同侧重。

**对课程的帮助：** 老师本课说明日辰很重要，但明确说当天先不展开完整日辰规则。因此本页不把古籍日辰章内容写成第十课课堂知识已确认。

## 4. 三合局

- [《增删卜易·六合章第十九（二）》（天机策）](https://divination.mczwl.cn/guji/zengshan/zsby-26)：列出申子辰水局、巳酉丑金局、寅午戌火局、亥卯未木局，以及一卦内动静、变爻凑局等成局方式；也说明三合局要看占问类别，求财形成兄弟局未必有利。
- [《增删卜易》原文与白话译注（Libo）](https://libokang.com/zh-hant/classics/liuyao/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93/)：提供三合局的常见组合与不同占事中如何观察局的方向。

**与课程差异：** 本课老师明确说日月可以参与三合，并以用神与月日组成三合为教学例子。但古籍章节对卦内动爻、变爻凑局和局成条件另有细分。课程没有完整讲完这些门槛，故本项目暂不把外部成局规则写成最终算法。

## 5. 伏神与飞神

- [《增删卜易·月将章第十六》（维基文库）](https://zh.wikisource.org/zh-hant/%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93/16)：明确提到用神伏藏被飞神压住时，月建可能冲克飞神、生助伏神而使伏神得用。
- [《增删卜易·四时旺相章》（识典古籍）](https://www.shidianguji.com/book/XYXZSBY/chapter/1lzxsn553lws2)：同样提到月建对飞伏的影响。

**对课程的帮助：** 本课买房案例正是以父母爻用神伏藏为例讨论月建作用，但 ASR 缺少完整卦盘，故只记录机制线索，不把“丑月必能买成房”当成通用应期。

## 6. 项目使用原则

1. 先记录真实起卦日期，明确年、月、日，不把公历月份直接等同于月建。
2. 月建与日辰分开计算并显示，不能只留一个合并后的“旺衰分”。
3. 所有三合关系都应显示参与地支、来源（卦爻/日辰/月建）、合成五行局，以及对当前用神的关系。
4. 月破、旬空和伏神要保留条件与时间窗口，不作一次性、无条件的吉凶判定。
5. 课程口径与古籍/现代注解不一致时，记录差异，不静默合并。
