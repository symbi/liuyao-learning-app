# 第十五课外部参考登记

> 本文件用于对照“求官/功名、官鬼、父母、子孙”等课堂术语。古籍观点仅作为传统文献参照，不代表老师本课逐条引用或完全采用。课程内容与外部文献必须分开记录。
>
> 检索日期：2026-11-07。

## 1. 《增删卜易·序》

- [维基文库：《增删卜易·序》](https://zh.wikisource.org/zh-hans/增删卜易/序)

可对照的内容：

1. 文中以“旺官持世”或官星发动生合世爻作为求功名的有利线索。
2. 文中把子孙持世、子孙发动列为入场/升迁时的不利线索。
3. 对现任官员的年度占问，文中提到官星持世、财动生之；同时还要求检查官鬼是否受克、世爻是否空破、是否化回头克等。
4. 文中把求财问题与官鬼、财爻、子孙爻的关系另行讨论，说明相同六亲在不同问题中不能脱离问事目标解释。

**与本课的关系：**“求官以官鬼为核心”“子孙可能制约功名”“财爻与官鬼存在生扶关系”有传统文献对照。但本课关于初入职场与在职升迁的细分，古籍序文不能直接替老师补完。

## 2. 《增删卜易·用神章第八》

- [维基文库：《增删卜易/8·用神章第八》](https://zh.wikisource.org/zh-hans/增删卜易/8)

可对照的用神分类：

- 父母爻：父母、师长、宅舍、屋宇、章奏、文书、文契等；
- 官鬼爻：功名、官府等；
- 子孙爻：子孙、医药等，并称其有制鬼、解忧、剥官等象义；文中单独指出占功名忌之；
- 妻财爻：妻妾、财物等。

**与本课的关系：**这能帮助核对本课中父母、官鬼、妻财、子孙的传统基础象义；但“父母爻代表某一家私企/单位”的具体课堂用法，不能仅凭该用神章就视为古籍原文。

## 3. 《增删卜易·八宫图第三》

- [维基文库：《增删卜易/3·八宫图第三》](https://zh.wikisource.org/zh-hans/增删卜易/3)

该篇先给出简化的功名判断线索，随后讨论者进一步提出：若官鬼或妻财旬空、月破，或受子孙/兄弟发动冲克，单凭官鬼持世、妻财持世是否足够。答语强调还要继续检查旬空、月破、生克、冲刑等条件。

**与本课的关系：**可用于支持一个重要学习边界：官鬼持世不是脱离全盘条件的“成功保证”；应结合旺衰、空破、动爻和世爻关系继续判断。

## 4. 《卜筮正宗·卷三·用神分类定例》

- [识典古籍：《卜筮正宗》卷五/卷三用神分类定例](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpdr8oqhb)

该页面列举父母、官鬼、兄弟、妻财、子孙等用神分类，其中功名官府以官鬼爻为用；父母与文书、宅舍等相连；子孙与医药、解忧等相连。

**与本课的关系：**作为交叉核对资料；具体版本卷次和篇章编排以所引用页面为准，不用于取代课程本身的问答。

## 5. 课程与外部资料的差异/边界

1. 古籍可支持“功名以官鬼为用”“求功名忌子孙”等基本取象，但不能直接推出每一种现代私企求职、内部升职和跨单位调动都使用相同规则。
2. 本课老师将父母爻用于观察单位/组织，并将体制外求职更多联系到妻财爻；这属于课堂应用线索，需以老师完整例盘核对。
3. “财生官”是五行关系层面的解释，但财爻在初入职场与已有职位求升迁时是否采用同样权重，本课 ASR 不足以恢复准确条件。
4. 老师举出的医生、律师、文艺/文化岗位等特殊语境，不能凭古籍一句“子孙制鬼/剥官”就归纳成可编程的统一例外表。
5. 传统术数中关于疾病、健康的文字不能作为医学判断。本项目只保存文化学习笔记，不输出诊断、治疗或疾病预测。

## 6. 本课核对结论

- **可以作为课堂与古籍共同线索记录：**求官主看官鬼；父母、妻财、子孙有各自的相关象义；判断仍需考虑旺衰、空破、动变与问事目标。
- **只属于本课课堂线索，待例盘核实：**体制外求职偏看妻财、父母代表单位、年岁/月建对应不同层级领导、第一卦作为长期事项总体参照。
- **暂不固化：**多重官鬼的取用、初入职场财爻权重、医生/律师等职业特例、调动与择日算法。
