# 第十六课外部参考登记

> 本文件用于对照求财、财爻、子孙元神、兄弟劫财、接续相生和三合局。外部文献只作为对照，不代表老师本课逐条引用或完全采用。
>
> 检索日期：2026-11-09。

## 1. 《增删卜易·序》

- [维基文库：《增删卜易·序》](https://zh.wikisource.org/zh-hans/增删卜易/序)

文中概述求财的若干判断线索，包括财星持世、日月或动爻以子孙生合世、官鬼持世而财动生之、父母持世而财动克之，以及兄弟持世或兄弟发动可能造成阻碍。

**与本课的关系：**可以对照“求财不能只看一爻，还要看财、子孙、兄弟和世爻之间的关系”。但本课更强调项目投入、三合取法和现金流等课堂扩展内容。

## 2. 《增删卜易·求财章第六十八》

- [维基文库：《增删卜易》全文（求财章第六十八见卷三）](https://zh.wikisource.org/zh-hans/增删卜易)
- 章节位置：全文“求财章第六十八”段落。

章节可对照的主要观点：

1. 妻财为求财用神，子孙是生助财爻的元神；财与子孙都宜有力、化吉，并能生合世爻。
2. 财爻与子孙爻都不现，或休囚、空破、墓绝、受冲克时，文中提出求财无益、不如守株待兔；同时也保留日月为财、伏神旺等例外。
3. 兄弟是劫财之神；兄弟与财同动可能造成阻隔破耗，但兄弟与子孙同动时，兄动生子、子动生财，形成较长的财源链。
4. 兄弟和财同动时，官鬼发动制兄弟，也可能有助求财。
5. 父母爻发动克子孙元神、兄弟爻发动克财，均被列为求财时需要警惕的关系。
6. 兄弟持世一般不利求谋，但章节同时给出特殊卦例，提醒不能机械套用。

**与本课的关系：**本课“兄弟→子孙→妻财”的接续相生，以及官鬼制兄弟、财福俱无不宜强求，与该章有明显对照。要注意古籍还提供了老师本课 ASR 未完整讲清楚的例外条件，不能直接把整章当作课堂规则。

## 3. 《增删卜易·用神章第八》

- [维基文库：《增删卜易·用神章第八》](https://zh.wikisource.org/zh-hans/增删卜易/8)

该章把妻财与货财、珠宝等财物相联系；把子孙称为福德之神、制鬼之神、解忧之神，并列为财爻的生助来源；兄弟则在求财中有劫财、谋事中有阻碍等象义。

**与本课的关系：**可用来校验求财六亲的基础象义，但具体投资本金、现金流和债务方角色属于本课应用讨论，不能只靠该章确认。

## 4. 三合局参考

- [六爻学堂：经典古籍“021、三合”](https://www.6ygua.cn/Study/Chapter/1157)

该网页所录三合材料列举申子辰、巳酉丑、寅午戌、亥卯未四局，并介绍三爻发动、两爻发动一爻不动、动爻变出三合，以及日月参与等情形。文中也强调三合有吉有凶：求财时，财局、子孙局与兄弟局的作用方向并不相同。

**与本课的差异：**网页所录传统说法允许若干跨爻位/动变方式参与成局；本课老师强调三合要纯粹、不能随意把上卦与下卦拆开拼凑，对模棱两可的组合不轻易认定。后续应以老师完整原音、板书及完整卦例继续核对，不能把网页上的通行说法直接替换老师口径。

## 5. 本课核对原则

- 妻财、子孙、兄弟的求财关系可以与《增删卜易·求财章》交叉核对。
- 接续相生和官鬼制兄弟有古籍对照，但实际是否成立仍须看旺衰、动静、空破、变爻和世爻关系。
- 三合必须区分课堂口径与外部文献口径，尤其不能把“可能成局”当成“已经成局”。
- 父母爻与项目垫资/慢回款、子孙爻与启动资金、债务追讨的用神映射属于课堂应用线索，当前没有足够材料做成通用算法。
- 投资、借贷、债务与抵押属于现实财务决策；笔记仅整理传统术数课程内容，不替代现金流测算、合同审查或专业法律/财务意见。
