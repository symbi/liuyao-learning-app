# 第十七课外部参考登记

> 本文件对照求学、求名/功名、父母与官鬼用神、兄弟竞争、六冲六合和应期。古籍内容只用于核对传统说法，不能代替老师本课针对现代学校教育和父母代问孩子的补充讲法。
>
> 检索日期：2026-11-12。

## 1. 《卜筮全书·求名》

- [识典古籍：《卜筮全书·求名》](https://www.shidianguji.com/book/HY1394/chapter/1l3wdpl9z8njc)

与本课主题直接相关的原文要点：

1. **父母与官鬼并看**：该篇说明父爻主文章，鬼位主宫职/功名，并称二者是一卦之主，缺一则不成。
2. **财爻、子孙爻在求名中的限制**：该篇指出财能克父、子孙能克官，因此求功名时财、福二爻发动或旺动不利；但静而休囚与发动当权有所区别。
3. **兄弟为同场竞争者**：兄弟被解释为与求测者同经之人；兄弟发动，或日辰/月建俱带兄弟，意味着同场竞争者多，可能夺标。
4. **日辰扶助**：父母、官鬼无气时，日辰扶起或制约不利因素，仍可能有希望；日辰也被描述为亲友劝进、资助等辅助力量。
5. **官父喜合不喜冲**：求名卦以官、父为用，篇中提出喜合不喜冲。
6. **考试卦喜安静**：篇中提出六爻皆静、父母官鬼有气而不空、日月不伤克较好；乱动则容易不顺。
7. **六合与六冲**：篇中认为求名遇六合较易、六冲较难，但仍明确提醒需要结合旺衰动静，不可执着于单一标签。
8. **三合**：篇中提到父母、官鬼三合相逢与功名相关；财、福二局在求名中则不利。具体成局条件仍须结合原文和所用流派。

**与课程的关系：**本课中老师讲父母、官鬼、兄弟竞争、财与子孙对求名的影响，以及考试喜安静、喜六合、不喜六冲，与《卜筮全书·求名》有较明显的对应。老师对现代家长替孩子问学，额外要求考虑子孙爻，是本课特别提出的现代代问补充，不应伪称为这篇古籍原有条文。

## 2. 《卜筮正宗·用神分类定例》

- [识典古籍：《卜筮正宗》卷三·用神分类定例](https://www.shidianguji.com/book/AMNL0060/chapter/1ma05ao3rvqqy)
- [识典古籍：卷五相关文本页](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpdr8oqhb)

该篇将父母爻与父母、师长、文章、章奏等联系；将官鬼爻与功名、官府等联系；将兄弟爻与兄弟、同寅及朋友等联系；将子孙爻与子女等联系。

**与课程的关系：**可用于对照父母/文章、官鬼/功名、兄弟/同辈竞争的传统象义。但本课“父母替孩子问学时还要看孩子本身的子孙爻”是老师针对现代家庭问事提出的补充。

## 3. 《增删卜易·序》

- [维基文库：《增删卜易·序》](https://zh.wikisource.org/zh-hans/增删卜易/序)

该序提出，求功名若官鬼旺而持世，或动爻官星生合世爻，可视为有利线索；若子孙持世或子孙在卦中发动，则不利入场、升迁等功名问题。该序也提醒要检查旬空、月破、四时旺衰和生克冲刑。

**与课程的关系：**支持本课中求名要看官鬼、子孙可能克制官鬼，以及不能脱离日月旺衰与空破判断的原则。古籍中的“功名/入场”范围不等于所有现代学校选择和学生学习问题。

## 4. 《增删卜易·各门类应期总注》

- [《增删卜易》各门类应期总注](https://www.chenshupaipan.com/books/6613/5104.html)
- [另一整理页：各门类应期总注](https://tjxsgw.com/iching/buyi/z30.html)

该条列出：
- 静而逢值、逢冲；
- 动而逢合、逢值。

**与课程的关系：**与本课“静逢值冲、动逢值合”的课堂口径相近。具体应期仍须先确认主事爻、动静、五行地支和现实问题，不可仅凭口诀直接生成日期。

## 5. 课程讲法与外部文献的边界

1. **学校/学业与功名不可混同。**本课老师把学校和求学以父母爻为主；对考编、正式职位和求功名，则强调父母、官鬼都要看。古籍的求名篇主要讨论功名、考试和录取，不直接涵盖所有现代学校咨询。
2. **父母代问孩子是现代问事主体变化。**老师提醒当父母替孩子问学校时，还需把孩子本身的子孙视角加入；这是老师的现代应用补充，不能说成所有古籍一致规定。
3. **求名忌财/子孙与求财喜财/子孙是两套不同语境。**不可将第十六课求财规则直接复制到本课考试规则。
4. **兄弟爻作为竞争者有古籍对照。**具体竞争人数、是否一定落榜仍取决于动静、旺衰、日月及其他爻关系。
5. **六冲/六合不是绝对预测。**古籍自身也强调结合旺衰动静，不可执滞。
6. **旬空有问事类型差异。**本课老师强调求名/考试不能只等待出空；过程性事项的旬空应期与明确结果类问题不同。
7. **应期口诀不等于确定日期。**“静逢值冲、动逢合值”只是一类候选方法，需要结合主事爻和完整卦盘。
8. **不得将求名卦用于保证录取。**考试名额、竞争者和现实条件都可能影响结果；课程笔记只记录老师讲法，不作百分之百承诺。
