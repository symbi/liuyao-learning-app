# 第七课外部参考：六亲动变、进退神与日月

> 外部网页仅用于理解基础术语和比较公开规则，不代表老师原话。不同体系可能有差异，尤其是进神/退神组合与具体断语条件。本项目记录差异，不自动把任何网页升级为权威规则。

## 1. 进神与退神

- [《增删卜易·进神退神章》在线文本](https://www.shidianguji.com/mid-page/7543003298585296942)：列出化进/化退组合，并明确说明吉凶要看喜忌。
- [李顺祥《卦爻进退新论》](https://www.sxw.cc/e/action/ShowInfo.php?classid=12&id=69)：列出传统进退组合，并说明进退吉凶取决于用神、原神、忌神、旺衰等因素。
- [六爻进神退神与应期介绍](https://bbscn-ly.luckerhome.com/article/webTopicPage/6/6009736.html)：包含不同整理口径及案例说明。

**项目备注：**《增删卜易》在线文本的进神列表不包括“戌化丑”，现代公开整理有列入的。具体差异需保留出处，不能静默合并成一个最终表。

## 2. 日辰、月建

- [青岚六爻基础：日辰](https://www.zhaosir.online/Books/BookChapterDetail.aspx?did=693)：讨论日辰对卦中爻的生克、冲合和旺衰作用。
- [六爻旺衰对照表](https://guoxue.app/zh-CN/library/liuyao/theory/liuyao-theory-ch-37)：提供月建旺衰及日建关系的速查内容。

**项目备注：**这些来源足以帮助理解日月是重要的判断因素，但某些量化体系及具体例子未必与课程完全一致。程序首先应保存起卦时间、月建、日辰及可追溯的关系，不能采用未经核实的简单加减分。

## 3. 六亲动化口诀

- [六爻六亲爻动化诀](https://www.zhanbu.org/detail/1648)：收录五种六亲爻动化的一种口诀与解释。
- [刘恒注解六爻六亲变化歌](https://fengshui678.com/show/972.html)：另一种六亲变化的解释路径。

**项目备注：**这些民俗术数解释属于特定传统体系，不应当成必然的现实结果，也不能替代本课程的适用条件。若课程和外部口诀不一致，优先记录差异和来源。

## 4. 项目使用约定

1. 把课程内容、外部资料与整理者推断分开。
2. 任何六亲化爻规则都要记录问事、旺衰、日月、变爻等适用条件。
3. 不把“化进必吉”“化退必凶”或某六亲变化直接映射成程序的硬性吉凶结果。
4. 不在缺少完整卦盘时，把课程口头例子伪装成可复算的测试用例。
