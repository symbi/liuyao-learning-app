# 第十一课外部参考：日辰、暗动与日破

> 本页只用于对照传统文献，不代表老师课堂原话。特别是“静爻被日辰冲后究竟按暗动还是日破”，本课老师的处理口径与传统古籍文字存在差异，项目应保留差异，不要静默统一。

## 1. 《增删卜易·日辰章第十七》

- [维基文库：《增删卜易》日辰章第十七](https://zh.wikisource.org/zh-hans/增删卜易/17)
- 章节将日辰视作六爻判断的重要时间因素，讨论日辰对旺衰、冲合、旬空和月破的作用。
- 其关键区分是：日辰冲旺相的静爻，称为暗动；日辰冲衰弱的静爻，称为日破。
- 章中还讨论冲空、冲合、日辰扶助/克制等情况，说明不能把所有日冲简单等同于一种结果。

## 2. 《增删卜易·暗动章第二十二》

- [识典古籍：《增删卜易》暗动章第二十二](https://www.shidianguji.com/book/XYXZSBY/chapter/1lzxsnhvbt0re)
- [赵Sir：暗动章第二十二](https://www.zhaosir.online/Books/BookChapterDetail.aspx?did=527)
- 传统文本同样区分：静爻旺相而受日辰冲为暗动；静爻休囚而受日辰冲为日破。
- 原文明确暗动“有喜有忌”：用神休囚时，原神暗动生用神可以有利；若忌神暗动克害用神，则为不利。
- 传统例子以原神暗动生扶子孙用神为例，说明暗动不能只按“有动就是凶”理解。

## 3. 与第十一课课堂口径的差异

| 对照点 | 传统文献常见文字 | 第十一课可辨认的老师口径 |
|---|---|---|
| 旺相静爻被日辰冲 | 暗动 | 暗动 |
| 休囚静爻被日辰冲 | 日破 | 老师说不再按旺相/休囚区分，只要日辰相冲就按暗动 |
| 暗动吉凶 | 有喜有忌，须看是否生用/克用 | 同样看原神、忌神、用神的实际关系 |
| 明动与暗动 | 分别处理 | 老师强调明动的爻不重复论暗动，其他静爻仍可各自暗动 |

**项目结论：** 这不是普通措辞差别，而是会影响排卦数据状态的规则差异。不得把老师说法悄悄改成传统规则，也不能未经用户/课程进一步确认，就把老师口径当作所有六爻流派的通则。

## 4. App 的实现建议

1. 保存日辰干支和被冲爻的地支。
2. 每条爻单独计算是否明动、是否暗动。
3. 将“暗动/日破”的判定策略做成可追溯规则配置，标注所采用的课程/传统来源。
4. 暗动后还要记录它生扶或克害的是哪一爻、是否作用于用神。
5. 对应案例未完整复原前，不把课堂口头示例设为自动化测试的唯一标准答案。
