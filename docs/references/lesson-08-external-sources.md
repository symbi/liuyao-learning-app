# 第八课外部参考：六神起例与象义

> 本页用于核对六神的基础排法及通用象意。外部页面不是老师课堂原文，也不能替代老师实际使用的取象口径。

## 1. 六神起例与自下而上排法

常见起例：
- 甲、乙日：初爻起青龙
- 丙、丁日：初爻起朱雀
- 戊日：初爻起勾陈
- 己日：初爻起螣蛇
- 庚、辛日：初爻起白虎
- 壬、癸日：初爻起玄武

起点确定后，按青龙、朱雀、勾陈、螣蛇、白虎、玄武的固定顺序，从初爻向上排到上爻。

## 2. 六神的常见五行与象意

部分公开资料将六神的五行对应归纳为：
- 青龙：木
- 朱雀：火
- 勾陈：土
- 螣蛇：土
- 白虎：金
- 玄武：水

常见象意概括：
- 青龙：喜庆、福禄、正向支持；
- 朱雀：言语、消息、文书、口舌；
- 勾陈：田土、房产、建筑、迟滞、牵连；
- 螣蛇：惊疑、怪异、隐忧、纠缠；
- 白虎：刚烈、权威、伤损、医疗/刀兵；
- 玄武：隐秘、盗骗、聪明、私下活动。

## 3. 权重与使用边界

公开资料同样提示，六神通常不能独立决定吉凶，需结合六亲、爻的旺衰及整卦关系。特别是“青龙必吉、白虎必凶”属于过度简化。

- [青岚六爻基础：六神](https://www.zhaosir.online/Books/BookChapterDetail.aspx?did=707) 举出青龙临不利爻也不能据此取吉、白虎临有利爻也不必然为凶的例子。
- [UAYA Foundation：六神](https://uaya.org/zh/learn/iching/advanced-studies/wen-wang-gua/hexagram-skeleton/six-spirits/) 将六神定位为修饰卦象语言的辅助注脚，而不是独立判词。

## 4. 项目使用原则

1. 排六神使用起卦日干，不使用月支直接确定起点。
2. 从初爻向上排，规则应有表格与单元测试。
3. 六神作为辅助显示项，不单独决定吉凶。
4. 六神的人格/职业取象要保留概率性和情境性，禁止根据单一标签断定某人的真实人格、职业或行为。
5. 课程口径与外部资料有差异时，记录差异，不静默合并。
