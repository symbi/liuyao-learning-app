# 第十四课外部参考登记

> 本文件登记婚姻与产育主题的古籍对照。外部文献只用于核对课程术语与识别潜在分歧，不代表老师本课逐条采用这些规则。
>
> 检索日期：2026-11-05。

## 1. 《卜筮正宗·婚姻》

- [识典古籍：《卜筮正宗全书·婚姻》](https://www.shidianguji.com/book/HY1439/chapter/1m70sjdkeqscv)
- [中国哲学书电子化计划：《卜筮正宗》婚姻篇](https://ctext.org/wiki.pl?chapter=801184&if=gb)
- [识典古籍：《卜筮正宗》卷六相关婚姻章节](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpidfmmug)

相关内容摘要：

1. 婚姻章讨论阴阳匹配、内外卦、世应相生相合、六合/六冲、财官动静、父母爻与翁姑/妯娌关系，以及媒人所对应的间爻。
2. 章节提到世应相生、相合的和谐线索，也谈到冲克、空亡、发动带来的阻碍；这些均需结合卦盘，而不是单一标签断定。
3. 章节末尾明确提醒：不能把所有婚姻问题一概定为官鬼代表丈夫、妻财代表妻子。男自占女婚、女自占男婚，与父母替子女择偶、兄弟替兄弟姐妹问婚，必须按具体求测关系和用神判断。
4. 《卜筮正宗》卷六还将媒人和中间人的问题与间爻联系起来，但若直接占问媒人本人，取用又另有区别。

**与课程的关系：**本课关于世应/世用、财官取用、父母爻及媒人间爻的讲授，与此类古籍话题相关。特别是“自占婚姻”与“代占亲属婚姻”必须分开，是值得保留的核心边界。

## 2. 《卜筮正宗·辟〈易林补遗〉婚姻嫁娶之谬》

- [识典古籍：《卜筮正宗》卷三](https://www.shidianguji.com/book/AMNL0060/chapter/1ma05ao3rvqqy)
- [001文学网：《卜筮正宗》相关原文](https://www.001h.cn/dianji/%E5%8D%9C%E7%AD%AE%E6%AD%A3%E5%AE%97/%E7%AC%AC2%E6%AE%B5/)

该段特别区分：

- 女人自己问嫁此郎，以官鬼爻为夫、世爻为自己；
- 男人自己问娶此女，以妻财爻为妻、世爻为自己；
- 父母尊长替子孙问婚配，以子孙爻为用；
- 兄弟姐妹替兄弟姐妹问婚配，则要按兄弟爻等具体亲属关系取用。

**注意：**这是古籍的一套具体取用表述，不能未经核对就认定为本课程所有婚姻场景的唯一规则。具体卦例仍需确认求测者、所问对象和代占关系。

## 3. 《卜筮正宗·产育》

- [识典古籍：《卜筮正宗》卷六产育章节](https://www.shidianguji.com/book/HY0057/chapter/1lpdfpidfmmug)
- [中国哲学书电子化计划：《卜筮正宗》产育章节索引](https://ctext.org/wiki.pl?chapter=801184&if=gb)

可核对的章节结构：

1. 先论子孙与孕育，并谈胎福相关取象；
2. 随后将胎爻与子孙爻分开讨论；
3. 章节明确写到，若问有孕无孕，须详胎伏胎飞，并以胎爻为主，而不是直接只看子孙爻。

**与课程的关系：**老师在本课讨论胎爻的不同方法，并倾向以子孙爻作为较通用的观察标准。外部古籍明确把“是否怀孕”的判断交给胎爻，说明两者至少不能不加区分地合并。该规则标记为“有分歧/待核实”，等待老师后续课程或完整卦例确认。

**健康边界：**古籍中有大量关于孕期、胎儿、分娩风险的传统断语。这些内容不应作为现代医疗判断或孕产安全建议，本项目不把它们实现为健康预测功能。

## 4. 《卜筮正宗·用神分类与世应论》

- [识典古籍：《卜筮正宗》卷三·用神分类定例、世应论用神](https://www.shidianguji.com/book/AMNL0060/chapter/1ma05ao3rvqqy)

该文把世爻视为自己、应爻视为他人，并列举父母、官鬼、兄弟、妻财、子孙各自对应的亲属或事项类别。它有助于检查代占问题中的取用神，但仍必须根据本次占问的对象和亲属关系具体判断。

## 5. 项目记录原则

- 婚姻问题不能不问求测主体就固定以财为妻、官为夫。
- 代问子女、兄弟姐妹婚姻，要先明确亲属关系再取用神。
- 世应、世用、间爻分别记录各自所代表的关系，不互相替代。
- 胎爻和子孙爻分别存储，等课堂讲法、完整例盘与古籍差异核对后再决定是否进入自动计算。
- 任何孕产健康推断都不作为医疗结论，也不应用于延误就医或替代专业检查。
