# 待决策清单（Open Decisions）

> Phase 0 交付物。本清单登记**尚未拍板的技术与口径决策**，与 `docs/rules-status.md`（规则核对登记）互补：规则「内容是否正确」记在规则状态表；「项目采用哪个口径/方案」记在这里。任何条目不得在用户确认前被标记为已决策；实现代码中对应位置必须按 `docs/architecture.md §6` 显示待确认状态。

## 状态定义

- **待决策**：尚未讨论或尚未由用户/课程资料拍板。
- **讨论中**：已有候选方案与权衡，等待确认。
- **已决策**：用户明确确认，注明决策日期与依据；实现须记录到 `docs/architecture.md`。
