# 第九课整理稿 v0.1：用神、原神、忌神与仇神

## 1. 本课主线

本课围绕以下几个环节展开：

1. 断一件具体事情时，先确定问的是什么，再找对应的用神；
2. 根据用神的五行关系，找生用神的原神、克用神的忌神，以及克原神/生忌神的仇神；
3. 分析动爻时，不能只看单个爻的生或克，要追踪连续相生、贪生忘克及其最终作用对象；
4. 区分具体世爻与应爻之间的关系，不用上卦、下卦代替世应爻关系；
5. 用神旬空、伏藏时，要继续检查原神、日辰月建等因素，不能简单把“空”当作绝对无用；
6. 项目、财运、年度趋势、健康和亲属占问，必须先把问题范围和求测关系说清楚。

## 2. 用神：先问清楚具体要占什么

### 2.1 课程强调

老师将“先找用神”放在具体事情断卦的第一步。用神不是一个不随问题变化的固定爻；同一张卦，提问目标不同，分析重点也不同。

课程举到的可辨认例子：

- 问父母的事情，或由子女代父母问父母病情，老师明确说应以**父母爻为用神**，不能只因问题是疾病就直接改用官鬼。
- 求官、功名、官司，以及女性问丈夫等例子，课程提到**官鬼爻**。
- 问财、收益或具体经营项目时，课程讨论**妻财爻**；同时还要看生财的原神，不能只看财爻一个标签。
- 讨论自己身体健康时，老师提到先看世爻，并留意子孙爻；转录里关于“通常不看官鬼”的完整前提不清楚，因此不能推广成所有健康问题都不看官鬼。
- 亲属、姻亲关系的取用必须说明“是谁问谁、目标与卦主是什么关系”。本课的姐夫、妹夫、嫂子等例子有明显 ASR 错字，具体对应暂不定稿。

### 2.2 年度趋势与具体事项

老师提到，流年/大运类整体趋势问题与日常一件具体事情不同，并说年度类分析没有单一、固定的用神，卦中各爻可能分别对应不同方面。

但这段 ASR 把相关术语和例子识别得不完整，尤其“每个爻代表什么方面”的对应内容不够清晰。因此这里只保留“整体年度趋势不能直接替代具体事情用神”这一课程线索；具体规则列为待核对，不据此制作自动排盘逻辑。

### 2.3 项目问题：问项目本身，不问不相干的外部事件

这是本课最清楚、最实用的方法论例子之一。

老师举例：某人关心一条高铁何时开通，是因为高铁开通后，自己的项目可能可以实施。老师认为，真正要判断的是**自己的项目能不能做、能否产生预期收益**，而不是把“高铁能不能开通”当作自己的占问目标。

理由是：外部事件发生，并不必然意味着自己的项目成功；同样，外部事件暂时没有发生，也不等于自己的项目必然失败。项目还涉及合同、付款、施工、项目事故、回款及执行等多个环节。

老师也区分了“整体财运好不好”和“眼前这个具体项目能不能赚钱”：整体财运好，不能保证手上的每个项目都成功；整体财运差，也不能据此断定每个项目都失败。

**整理出的提问原则：**问题应落在自己实际要做、能参与或承受结果的那件事上，并明确时间范围。若问项目收益，妻财是需要观察的重要对象；子孙作为生财的原神也需要检查。至于具体项目如何建立完整用神结构，本课没有给出足以程序化的统一表格。

## 3. 原神、忌神、仇神：以用神为中心建立关系

这三个名称是相对于当前用神而言的，不应先把某个六亲固定标成“永远是原神”或“永远是忌神”。

| 名称 | 本课可辨认的定义 | 关系方向 |
|---|---|---|
| 用神 | 当前所问事情的核心代表爻 | 先由问题确定 |
| 原神 | 在五行上生用神的爻 | 生用神 |
| 忌神 | 在五行上克用神的爻 | 克用神 |
| 仇神 | 制克原神、同时生扶忌神的爻 | 克原神、生忌神 |

老师在解释仇神时，还用“用神所克”作简化辨认线索。外部《卜筮正宗》文本也将仇神解释为“克制原神、生扶忌神者”。程序实现时应以明确的五行关系推导，并保留每一步关系，不要只依赖六亲名称。

### 3.1 原神

- 原神的作用是生扶用神。
- 用神偏弱、旬空、月破或伏藏时，课程提醒要继续检查原神是否发动、是否真正能生扶，以及日辰月建是否提供帮助。
- 原神若休囚、不动，或自身发动后反而变墓、变绝、变克、变破、变退，可能无法有效生用。
- 因此不能仅仅看到卦中“存在一个原神”就认定用神已经得到帮助；还要检查它是否有力量、是否发动及其动变结果。

### 3.2 忌神

- 克用神的爻为忌神。
- 忌神发动克用神，是需要重点检查的不利关系。
- 但不能只看到忌神发动就结束判断，还要看用神是否旬空或伏藏、是否有原神发动生扶、忌神是否被制或回头克，以及日辰月建的作用。
- 本课和《卜筮正宗》相关文字都提到：若忌神发动，而原神也发动生用，可能出现“贪生忘克”的关系变化，不能把忌神的克简单地视为已经直接伤到用神。

### 3.3 仇神

- 仇神是克制原神、又生扶忌神的爻。
- 老师强调仇神发动时，原神会受伤，用神可能失去根源，而忌神得到加强。
- 这也是为什么不能只检查用神与忌神的直接生克；还要往外追踪原神与仇神之间的关系。

## 4. 多爻发动：连续相生与“贪生忘克”

### 4.1 接续相生的课堂例子

老师给出两个项目结构作比较。ASR 对完整卦盘及个别爻名识别不清，但能辨认的核心对比是：

- 结构一：生财的关系较直接；
- 结构二：兄弟爻发动生子孙爻，子孙爻再生妻财爻，形成连续的相生链。

老师倾向于认为第二种链条更有利，并称为**接续相生**，同时用“贪生忘克”解释：兄弟爻通常可能克妻财，但当其发动后转而生子孙，子孙又继续生财时，分析不能只停留在“兄弟克财”这一条静态关系上。

### 4.2 课程要点

- 先标出所有发动爻；
- 分别记录它们与本爻、变爻及其他关键爻的关系；
- 若出现连续相生，继续追踪力量最终落到哪里；
- 检查原神是否被生扶、忌神是否得到帮助、仇神是否伤及原神；
- 不要把所有生克关系机械抵消成一个总分。

“贪生忘克”是课程采用的解释概念，不等于所有连续相生都必然有利，也不代表可以忽略旺衰、日月、回头生克和具体问事。完整项目例盘缺失，不能作为程序测试的固定答案。

### 4.3 仇神发动的影响

课程讲到，仇神发动会伤原神、使忌神得到加强。课堂转录中的解释与《卜筮正宗》“仇神发动，则原神被伤，用神无根，忌神倍力”的原文方向相符。

## 5. 世爻与应爻：看具体爻，不看上卦与下卦代替

本课特别提醒：世爻和应爻是卦中的具体爻位。分析两者关系时，应比较实际的世爻、应爻及其五行关系，而不是简单把上卦和下卦当成世应双方。

课程举例时指出，两件事可以同时成立：

- 整个卦可能是六冲卦；
- 具体世爻与应爻之间，仍可能是比和或其他五行关系。

因此应分别记录：
1. 卦整体的卦名及六冲/六合等类别；
2. 世爻实际所在爻位及五行；
3. 应爻实际所在爻位及五行；
4. 世应两爻之间的比和、生、克、冲、合关系。

老师给出的概括倾向是：世应比和、相合通常较和顺；世应相冲、相克通常不利于双方关系。但老师也表示疾病、婚姻等具体章节还会用案例细讲，所以目前不能把这些方向写成脱离问事背景的硬性吉凶规则。

## 6. 用神旬空、原神与伏神

### 6.1 用神旬空与原神

课程以求财为例，讨论妻财用神旬空，而卦中子孙原神发动生财的情况。老师的解释方向是：用神在当前时点仍可能处于旬空状态，但若原神发动生扶，出空之后可能恢复作用；若原神不动或无力，空亡带来的问题可能更难得到补救。

这部分没有完整日辰、月建、旬空支及卦盘，故这里只登记为条件性线索。不能简化成“原神一动，旬空立即消失”，也不能把所有旬空一概判为真空无用。

### 6.2 伏神问题

课程提到用神伏藏不现，并用考试问题追问“本卦安静、用神伏藏、又遇旬空”应如何理解。但关键问答被 ASR 识别得很差，尤其关于“伏神与旬空能否同时出现”的那句话，无法可靠确定。

因此：
- 不把转录中的疑似“伏神不能同时旬空”写成正式规则；
- 不用这段转录去改写第六课关于伏神的内容；
- 后续需要音频或更清晰的课堂记录才能确认。

## 7. 健康及代占的课堂例子

### 7.1 子女替父母占父母病情

老师明确提出：父母无法自行摇卦、由子女代为占问父母病情时，应该以**父母爻为用神**，不能仅因问的是疾病就机械换成官鬼。

### 7.2 自身健康

老师提到自身健康问题要先看世爻，并注意子孙爻；同时指出不能将“官鬼”不加区分地套用到所有健康问题。由于完整案例和上下文不全，本课不形成统一的健康排盘算法。

### 7.3 案例保存限制

本课出现父母目前健康、未来某些月份可能有问题，以及财爻/子孙/官鬼等组合的讨论，但缺少完整卦盘、准确日月、爻位及可靠的最终反馈。本文保留老师讨论的思路，不判断当事人的现实健康，也不把这些内容做成程序测试数据。

## 8. 应期与其他尾段内容

转录末段出现“卯月”“子日”等应期讨论，但月份、日期、卦例和口诀上下文无法完整复原，不提炼为可执行的应期规则。

课程结尾还转入十二长生、三合等内容，但 ASR 识别和讲解均不完整。本课暂不建立十二长生或三合规则表，避免根据残句补造组合。

## 9. 本课可先落实的学习/程序原则

1. 先明确问题对象、问题范围和时间范围，再确定用神。
2. 用神确定后，再按五行关系找原神、忌神、仇神。
3. 所有关系都要注明作用对象，不能把“生”“克”当成脱离目标的吉凶标签。
4. 多爻发动时保留每条关系链，尤其记录连续相生、贪生忘克与仇神伤原神的可能性。
5. 分开保存卦级六冲/六合与具体世应爻之间的关系。
6. 用神旬空或伏藏时，继续检查原神、日辰月建及出空/出伏条件；不能直接判无用。
7. 不能由整体财运推断某个特定项目必然成功，也不能把外部事件发生等同于自己的项目成功。

## 10. 待核对事项

1. “流年/大运”相关术语的准确说法，以及各爻在年度趋势中的具体分工。
2. 本课姐夫、妹夫、嫂子、弟妇等姻亲例子的准确用神对应；当前 ASR 无法复原师生问答。
3. 用神旬空、原神发动及“出空”之间的具体条件与时点。
4. 伏神与旬空是否可同时出现的课堂原话。
5. 世应比和、相合、相冲、相克在不同问事中的适用边界。
6. 项目一/项目二案例的完整六爻、六亲、日月、世应与变爻信息。
7. 父母健康案例的完整卦盘、日月、应期和最终反馈。
8. 卯月、子日应期案例的完整上下文。
9. 结尾十二长生、三合内容的准确术语、组合与适用范围。
