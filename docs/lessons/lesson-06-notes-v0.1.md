## 2. 动爻的整体理解

### 2.1 动爻与持世是不同维度

本课转录将“卦中的世应”和“六亲爻发动”区分开来。整理时必须分开记录：
- **世爻 / 应爻：** 说明卦中世、应的位置与关系。
- **六亲持世：** 看世爻属于哪一六亲。
- **六亲发动：** 看哪一爻发动，以及发动的爻属于哪一六亲。
- **变爻：** 动爻变化之后对应的爻；需要另行核对生克方向。

不能把“某六亲持世”和“某六亲发动”写成同一条规则。

### 2.2 动爻多寡

课程中可以辨认到的要点是：动爻越多，爻与爻之间需要分析的关系通常越多，解释也更复杂；只有一爻发动时，较容易把重点放在该动爻及其变化上。

这不代表“动爻少必然准确”或“动爻多一定不好”。具体判断仍要结合用神、动变关系和整卦。转录中关于“只考虑发动、不考虑日辰月建”的边界语句有识别矛盾，先记录为待核对，不擅自固化成算法条件。

## 3. 五种六亲爻发动：课程线索

以下是转录中可辨认的课堂方向，不等于完整断语规则。

### 3.1 官鬼爻发动

课程举到普通工作、体制内升职、领导与直接上级关系，也提到官司等场景。

- 问普通工作时，官鬼爻可能被用于观察领导/上级相关因素。
- 问公职、升职时，官鬼的状态及其与父母爻等的关系都需要看，不能把“官鬼发动”单独等同于升职成功。
- 课程讨论了官鬼与父母、子孙等爻之间的生克、动变关系，但转录噪声使部分具体组合不够可靠。
- 官鬼与六神的组合也被用于举例；例如白虎、青龙相关的安全、争执或乐极生悲等说法，应保留为传统取象案例，而不是当作必然事实。

### 3.2 父母爻发动

转录提到父母爻与工作支持、贵人、文书、名声/资格、诉讼证据等主题有关。

- 在工作或升职问题中，父母爻可能被用于观察领导支持、文书或资格等因素。
- 在诉讼相关例子中，老师把父母爻与文件、证据联系起来。
- 父母爻发动并不意味着所有问题都会变好；必须放回具体问题和爻之间的关系中。
- 本课有关父母发动的若干句子识别不清，不能确定的具体动变组合不直接写成硬规则。

### 3.3 兄弟爻发动

课程明确将兄弟与求财中的劫财、支出、竞争等联系起来，并讨论已经投入资金后如何面对不利局面。

- 在投资/生意案例中，老师提到如果卦象显示不利，不要因为已经投入很多就继续追加；可考虑及时止损或折价退出。
- 兄弟爻也被用于讨论同事、合伙人、家庭成员间的不和等关系问题。
- 具体是兄弟持世还是兄弟爻发动、是否同时有其他动爻，必须区分；缺少完整卦盘时不把该案例变成机械判断规则。
- 老师还结合白虎、青龙等六神举例，提醒同一爻的取象会随问事场景变化。

### 3.4 子孙爻发动

本课重复提到子孙爻对官鬼的克制关系。

- 在问官职、升职等问题时，子孙发动克官鬼可能是不利线索。
- 这不是说子孙发动在任何事情中都不好。应先确定问的是什么、哪一爻发动、它与官鬼或用神之间是什么关系。
- 具体组合与案例条件因转录错误较多，后续需要更清晰的课件/录音或其他课程补充。

### 3.5 妻财爻发动

课程围绕财运、生意投资、婚姻用神等场景举例，同时提醒不能因为妻财持世或妻财发动，就直接得出“可以大胆投资”之类结论。

- 先分清问的是财、工作、婚姻还是其他事项。
- 看妻财爻是否发动、化为何爻、与兄弟/子孙/官鬼等爻的关系如何。
- 不要把单一卦名、卦辞或某个六亲标签当作最终结论；老师在一个学生已经倾向报名课程的案例中，提醒要避免用卦象为已经做出的决定简单找理由。
- 该案例的卦名与具体爻位在 ASR 中不够可靠，暂不作为测试用例。

## 4. 用神不现与伏神

转录后半段出现了一个可以辨认的知识点：如果问事所需的用神在本卦明面上没有出现，不能直接说没有用神或停止判断，而是要进一步寻找伏神。

根据课堂可辨认的讲解顺序，先确认本卦所属卦宫，再查找该宫卦全图中代表所需六亲的爻，作为寻找伏神的依据。外部基础资料也把“本宫卦中查找缺失六亲，再按爻位处理伏神/飞神”作为常见讲法；但不同流派和实现项目对用神出现顺序、变爻及伏神的取用规则可能有不同约定，所以还不能仅凭这段转录确定完整算法。见 [外部参考登记](../references/lesson-06-external-sources.md)。

**当前可保留的规则线索：**
1. 先明确问事与用神；
2. 检查本卦六亲中是否明现用神；
3. 若本卦不现，继续按本卦所属卦宫和对应六亲规则查伏神；
4. 再判断伏神所在位置及与飞神的关系。

其中第 3、4 步的严格程序需要结合更清晰的课堂实例进一步核对。

## 5. 纳甲复习：艮卦地支

本课后半段有一段在复习纳甲、特别是艮卦的地支排列。转录识别有误，但与开源参考表对照后，可以先记录以下标准化的基础表述：

- 艮卦下卦（初爻至三爻）纳支：辰、午、申；
- 艮卦上卦（四爻至上爻）纳支：戌、子、寅。

这属于对基础纳甲表的外部交叉核对；具体课堂示例中由艮卦变化为另一卦后怎样重新排各爻，当前转录不足以可靠复原，暂不补造完整卦盘。参考：[woaichiji/liuyao：纳甲](https://github.com/woaichiji/liuyao/blob/main/2-03-%E7%BA%B3%E7%94%B2.md)。

## 6. 本课的案例类型

当前转录中可辨认出以下讨论场景，但没有足够数据复原完整卦盘：

- 求财/生意投资：兄弟与劫财、及时止损的讨论；
- 普通工作或公职升职：官鬼与领导关系、父母爻及其他动爻的影响；
- 官司/诉讼：父母爻与文书、证据的联系；
- 外出与安全：官鬼、六神的情境化取象；
- 婚姻问题：若用神不现，需要继续找伏神；
- 报名学习/课程：不应让卦名或已有倾向替自己做决定。
