## 2. 动爻的整体理解

### 2.1 动爻与持世是不同维度

本课转录将“卦中的世应”和“六亲爻发动”区分开来。整理时必须分开记录：
- **世爻 / 应爻：** 说明卦中世、应的位置与关系。
- **六亲持世：** 看世爻属于哪一六亲。
- **六亲发动：** 看哪一爻发动，以及发动的爻属于哪一六亲。
- **变爻：** 动爻变化之后对应的爻；需要另行核对生克方向。

不能把“某六亲持世”和“某六亲发动”写成同一条规则。

### 2.2 动爻多寡

课程中可以辨认到的要点是：动爻越多，爻与爻之间需要分析的关系通常越多，解释也更复杂；只有一爻发动时，较容易把重点放在该动爻及其变化上。

这不代表“动爻少必然准确”或“动爻多一定不好”。具体判断仍要结合用神、动变关系和整卦。转录中关于“只考虑发动、不考虑日辰月建”的边界语句有识别矛盾，先记录为待核对，不擅自固化成算法条件。

## 3. 五种六亲爻发动：课程线索

以下是转录中可辨认的课堂方向，不等于完整断语规则。

### 3.1 官鬼爻发动

课程举到普通工作、体制内升职、领导与直接上级关系，也提到官司等场景。

- 问普通工作时，官鬼爻可能被用于观察领导/上级相关因素。
- 问公职、升职时，官鬼的状态及其与父母爻等的关系都需要看，不能把“官鬼发动”单独等同于升职成功。
- 课程讨论了官鬼与父母、子孙等爻之间的生克、动变关系，但转录噪声使部分具体组合不够可靠。
- 官鬼与六神的组合也被用于举例；例如白虎、青龙相关的安全、争执或乐极生悲等说法，应保留为传统取象案例，而不是当作必然事实。

### 3.2 父母爻发动

转录提到父母爻与工作支持、贵人、文书、名声/资格、诉讼证据等主题有关。

- 在工作或升职问题中，父母爻可能被用于观察领导支持、文书或资格等因素。
- 在诉讼相关例子中，老师把父母爻与文件、证据联系起来。
- 父母爻发动并不意味着所有问题都会变好；必须放回具体问题和爻之间的关系中。
- 本课有关父母发动的若干句子识别不清，不能确定的具体动变组合不直接写成硬规则。

### 3.3 兄弟爻发动

课程明确将兄弟与求财中的劫财、支出、竞争等联系起来，并讨论已经投入资金后如何面对不利局面。

- 在投资/生意案例中，老师提到如果卦象显示不利，不要因为已经投入很多就继续追加；可考虑及时止损或折价退出。
- 兄弟爻也被用于讨论同事、合伙人、家庭成员间的不和等关系问题。
- 具体是兄弟持世还是兄弟爻发动、是否同时有其他动爻，必须区分；缺少完整卦盘时不把该案例变成机械判断规则。
- 老师还结合白虎、青龙等六神举例，提醒同一爻的取象会随问事场景变化。

### 3.4 子孙爻发动

本课重复提到子孙爻对官鬼的克制关系。

- 在问官职、升职等问题时，子孙发动克官鬼可能是不利线索。
- 这不是说子孙发动在任何事情中都不好。应先确定问的是什么、哪一爻发动、它与官鬼或用神之间是什么关系。
- 具体组合与案例条件因转录错误较多，后续需要更清晰的课件/录音或其他课程补充。

### 3.5 妻财爻发动

课程围绕财运、生意投资、婚姻用神等场景举例，同时提醒不能因为妻财持世或妻财发动，就直接得出“可以大胆投资”之类结论。

- 先分清问的是财、工作、婚姻还是其他事项。
- 看妻财爻是否发动、化为何爻、与兄弟/子孙/官鬼等爻的关系如何。
- 不要把单一卦名、卦辞或某个六亲标签当作最终结论；老师在一个学生已经倾向报名课程的案例中，提醒要避免用卦象为已经做出的决定简单找理由。
- 该案例的卦名与具体爻位在 ASR 中不够可靠，暂不作为测试用例。

## 4. 用神不现与伏神

如果问事所需的用神在本卦六爻中没有明现，不能因此停止判断；按本课学习口径，需要继续查找伏神。这里的关键不是直接猜一个伏神，而是先确定卦宫，再用本宫纯卦的纳甲地支和六亲关系逐爻定位。

### 4.1 伏神查找步骤

1. **先定问事用神。** 先根据具体问题确定需要找哪一六亲，例如工作调动问官职，主用神为官鬼。
2. **确定本卦所属卦宫五行。** 六亲关系以卦宫五行为“我”，不是以月建五行、日辰五行或某一动爻五行为“我”。
3. **检查本卦六爻是否明现该用神。** 以本卦六条爻的六亲为准；若没有出现目标六亲，继续查伏神。
4. **调出该卦宫的本宫纯卦。** 按本宫纯卦初爻到上爻的纳甲地支顺序逐爻排列。
5. **按卦宫五行重新确定本宫纯卦每一爻的六亲。** 找到目标六亲所在的爻位；该位置的纳甲地支与五行就是伏神。
6. **将伏神放在实际本卦相同爻位的飞神下面。** 同一位置上，实际本卦原有的爻为飞神；再分别记录伏神、飞神及两者的五行生克关系。

### 4.2 五行与六亲对应

以卦宫五行为“我”：

| 五行关系 | 六亲 |
|---|---|
| 与我同五行 | 兄弟 |
| 我生 | 子孙 |
| 我克 | 妻财 |
| 克我 | 官鬼 |
| 生我 | 父母 |

例如离宫属火，水克火，所以离宫的官鬼属水；火克金，所以离宫的妻财属金。

### 4.3 本宫纯卦的纳甲地支顺序

**分组记忆：** 乾、坎、艮、震为前四个阳卦一组；巽、离、坤、兑为后四个阴卦一组。查伏神时，不是只记卦名，而是要按该宫本宫纯卦从初爻到上爻逐位排出六个地支，再逐位确定六亲。

以下完整顺序均按**初爻 → 上爻**排列。前面三支是下卦（内卦），后面三支是上卦（外卦）。

| 卦宫/本宫纯卦 | 下卦三爻 | 上卦三爻 | 六爻完整顺序 |
|---|---|---|---|
| 乾 / 乾为天 | 子、寅、辰 | 午、申、戌 | 子、寅、辰、午、申、戌 |
| 坎 / 坎为水 | 寅、辰、午 | 申、戌、子 | 寅、辰、午、申、戌、子 |
| 艮 / 艮为山 | 辰、午、申 | 戌、子、寅 | 辰、午、申、戌、子、寅 |
| 震 / 震为雷 | 子、寅、辰 | 午、申、戌 | 子、寅、辰、午、申、戌 |
| 巽 / 巽为风 | 丑、亥、酉 | 未、巳、卯 | 丑、亥、酉、未、巳、卯 |
| 离 / 离为火 | 卯、丑、亥 | 酉、未、巳 | 卯、丑、亥、酉、未、巳 |
| 坤 / 坤为地 | 未、巳、卯 | 丑、亥、酉 | 未、巳、卯、丑、亥、酉 |
| 兑 / 兑为泽 | 巳、卯、丑 | 亥、酉、未 | 巳、卯、丑、亥、酉、未 |

### 4.4 伏神与飞神的关系

找到伏神后，要回到实际本卦同一爻位，记录该爻原有的地支、五行和六亲作为飞神。然后再比较伏神与飞神之间的生、克、冲、合等关系。

例如：
- 伏神五行生飞神：伏神生飞神；
- 飞神五行生伏神：飞神生伏神；
- 伏神五行克飞神：伏神克飞神；
- 飞神五行克伏神：飞神克伏神。

**不要只凭“伏神克飞神”或其他单一关系直接下吉凶结论。** 仍需结合用神旺衰、月建日辰、动变以及问事本身综合判断。第十课笔记另有月建作用于伏神、飞神的讨论，可交叉阅读[第十课整理稿](lesson-10-notes-v0.1.md)。
