## 1. 本课范围

老师将本课分为两部分：

1. **六亲持世**：世爻本身的含义，以及官鬼、父母、兄弟、子孙、妻财五种六亲持世的常见取象。
2. **案例解读**：一个公职人员问升职、一个私企职业经理人问新工作的案例。

## 2. 定位与基本关系

### 2.1 六爻位置从下往上编号

从下往上依次为：初爻、二爻、三爻、四爻、五爻、上爻（第六爻）。

- 下卦/内卦：初、二、三爻。
- 上卦/外卦：四、五、上爻。

### 2.2 世应关系

课程转录明确讲到：**先找到世爻，应爻与世爻相隔两个爻位**。这里“隔两个爻”是指中间隔着两个位置、编号相差 3；例如四爻对应初爻，五爻对应二爻，上爻对应三爻。

| 世爻位置 | 应爻位置 |
|---|---|
| 初爻 | 四爻 |
| 二爻 | 五爻 |
| 三爻 | 上爻 |
| 四爻 | 初爻 |
| 五爻 | 二爻 |
| 上爻 | 三爻 |

**重要区别：**这张表只说明“已知世爻后如何找到应爻”，并不能单独告诉我们某卦的世爻究竟在哪一爻。确定世爻位置还需要根据六十四卦的卦宫/世次规则（如本宫、一世至五世、游魂、归魂）定位。课堂转录本身没有在本课完整复讲整套世爻定位方法。

### 2.3 世爻与用神不可混为一谈

- 世爻：老师将其解释为问卦者自己、主动的一方、原始/主体力量。
- 应爻：对方或相对的一方；具体取象仍应结合所问事项。
- 用神：针对所问对象选取的六亲爻，例如问财常看妻财，问文书/学业常看父母，问职务常看官鬼。

不能因为某类六亲是用神，就把它和世爻当成同一概念。也不能只因上下卦相同，就直接推断问事双方关系相同；老师强调应进一步看世爻与应爻本身的五行关系，并结合六冲、六合等卦象信息。

### 2.4 五行与六亲的基础映射

传统六爻装六亲通常以**本卦所属卦宫的五行**作为“我”，再比较各爻地支五行：

| 五行关系 | 六亲 |
|---|---|
| 生我 | 父母 |
| 同我 | 兄弟 |
| 我生 | 子孙 |
| 我克 | 妻财 |
| 克我 | 官鬼 |

外部 GitHub 参考资料也采用这一映射，并说明变爻的六亲通常仍以本卦卦宫五行为基准；这属于**外部知识交叉核对**，不是本课逐字讲解。见 [woaichiji/liuyao：装六亲](https://github.com/woaichiji/liuyao/blob/main/2-04-%E8%A3%85六亲.md) 和 [ShousenZHANG/chinese-fortune：六爻参考规则](https://github.com/ShousenZHANG/chinese-fortune/blob/main/references/04-liuyao.md)。

## 3. 五种六亲持世：课程摘要

以下是对课堂讲解的忠实归纳，不表示单凭“某六亲持世”就能直接定吉凶。老师反复提醒要结合问事类型、动爻、五行生克、旬空、入墓、刑冲破害等因素。

### 3.1 官鬼持世

课程提到的取象包括：官职、功名、领导/权力；也可能涉及疾病、官司、压力或财务损失。

- 问升职、功名时，官鬼持世可以是有利线索，但不等于一定升职成功。
- 老师特别提到：若子孙爻发动克官鬼，可能不利于求官/升职。
- 官鬼若逢旬空、入墓或受其他爻作用，仍须继续判断，不能只看“官鬼持世”四个字。

### 3.2 父母持世

课程提到的取象包括：学业、功名、文书、证件、贵人/支持；同时也可能意味着操劳、进展不快。

- 问学业、文书、工作支持时，可以把父母爻作为需要观察的线索。
- 父母持世不保证所有事情都好；课程特别举到求子时可能不利的情形。
- 案例中父母爻力量强，也不自动等于升职一定成功。

### 3.3 兄弟持世

课程把兄弟与同辈、人际关系、花费/劫财等联系起来。

- 问财时，兄弟可能提示竞争、分财或钱财留不住。
- 但老师明确反对“兄弟持世无论问什么都一定不好”的绝对判断；要看实际所问的事情。
- 兄弟爻发动与兄弟持世是不同信息，不能混为一谈。

### 3.4 子孙持世

课程将子孙称为“福神”，并提到解忧、寻回失物等取象。

- 在课程举例的失物/宠物情境中，子孙相关信息可能是有利线索，但仍要观察动变。
- 问功名、官职时要特别注意子孙克官鬼，因此子孙持世并非在所有问事中都好。
- 子孙爻发动与化爻关系会影响判断，不能只看它是不是持世。

### 3.5 妻财持世

课程将妻财与钱财、财运联系起来；在男方问婚姻时，妻财也可能作为用神。

- 妻财持世可作为问财时的重要线索，但不代表任何情况下都必然有利。
- 课程提到财爻发动化兄弟，可能出现劫财/钱财损耗的判断。
- 课程也提到财化官鬼、官鬼化财可能与罚款、官司或公家支出等联系；该段 ASR 有明显识别噪声，老师说“为什么以后再讲”，所以这里只记录为**待进一步核对的课堂线索**，不作为已经掌握完整条件的规则。

## 4. 两个课堂案例

### 案例 A：公职人员问升职是否成功

**课堂结论：老师最后判断没有升职成功；同时明确承认该卦有争议。**

老师讨论的因素包括：
- 官鬼持世；
- 子孙爻发动并克官鬼，是不利线索；
- 父母爻力量强，可能代表有人帮助或有领导支持，但不一定能抵消其他因素；
- 官鬼爻发动生父母，老师认为这会削弱官鬼，因而影响升职判断；
- 卦中还提到六合等因素，因此课堂上存在不同解读。

**限制：**目前转录没有完整、清晰的卦盘图，也缺少可复现的全部爻位、地支、日月信息。保留老师的结论与争议，不伪造缺失盘面。

### 案例 B：私企职业经理人问新工作如何

**课堂结论：老师判断整体有利，可以去，待遇/薪酬可能符合预期。**

老师给出的理由包括：
- 妻财持世且静；
- 日、月对财爻有支持；
- 子孙爻发动生财；
- 父母爻力量较强，老师据此提到领导支持/认可。

**限制：**完整卦盘、日期和具体爻位信息未在当前转录中可靠保留。先保存课堂结论和理由，不要求补齐所有细节，也不把它直接变成自动化测试的标准答案。

## 5. 课堂练习与待核对点

转录末尾的选择题选项部分有 ASR 错误，当前不根据猜测补全答案。可以可靠归纳的课堂要点：

- 世爻受克与世爻持某六亲，是两种不同的判断。
- 官鬼持世不等于必然升官发财。
- 兄弟持世不等于问任何事情都不好。
- 妻财持世时，动爻变化可能改变原先的判断。
- 六亲的意义必须结合所问事项及整卦结构判断。
