# 第十五课整理稿 v0.1：综合案例分析（案例课）

> 课程日期：2026-11-06（按用户此前确认）。课程性质为综合案例课，不是单一主题专题课。  
> 来源：本轮上传的课堂 ASR 转录（`Pasted text(20261119-125916).txt`）。转录未经人工校订，存在同音误识、断句错误及卦盘信息缺失。本文只整理可辨认的课堂结构和讲解方向；无法复原的卦名、爻位、日月和动变信息不补造。

## 1. 本课结构

本课以多个实际卦例串联讲解，涉及工作调动、项目求财、店铺承接与转让、创业合伙、健康问答、投资和婚姻。各主题是同一堂综合案例课内的分类，不应把整堂课改名为健康课或求财专题课。

## 2. 工作调动：同一岗位的竞争关系

开头案例询问体制内工作调动能否成功。老师围绕世爻、应爻、父母爻及两重兄弟爻展开分析：

- 问题明确到一个具体岗位，重点是能否调动到该岗位，而不是泛问事业运。
- 卦中出现两重兄弟爻，老师将其作为两个竞争者/竞争关系来比较。
- 老师先比较世爻与竞争者的旺衰、日月帮扶，再比较双方是否发动、动变后是否得到回头生扶。
- 该例中另一兄弟爻发动，老师认为竞争者因此取得优势；最终倾向认为求测者成功机会较小，并建议不要在这件事上投入过多精力。

**限制：**ASR 中卦名、具体爻位、纳甲、动变及若干生克术语无法可靠辨认。本节不将其整理成可复现的标准卦例。

## 3. 求财与项目：项目能否做，不等于能否赚钱

转录讨论多个求财和项目案例，包括项目是否有利润、店铺是否适合承接、合同/店铺转让及创业项目是否可行。老师反复提醒：

- 先明确问的是项目能否启动、能否继续、能否盈利、资金是否到位，还是本人能否承接；这些不是同一个问题。
- 求财不能只看妻财爻，还要看子孙爻及其生财作用，同时检查世爻是否有力量。
- 兄弟爻可能带来竞争、劫财或耗损，但不能脱离其他爻的状态，看到兄弟就直接断完全无财。
- 店铺转让案例讨论了本卦与日月见财、原有财爻是否发动、是否持续生化等差别；不能把「日月见财」抽离完整条件单独使用。
- 对长期经营不佳、转让不出的店铺，老师讨论了是否再等待一段时间、是否及时止损。具体月份和应期因 ASR 识别不可靠，不抄成确定日期。

## 4. 创业与合伙开公司：不能只看财爻

老师讨论创业项目、合伙经营及开公司时，指出判断维度不应过浅：

- 先确认问题是「公司能不能开」「能否经营」「能否赚钱」还是「求测者本人承担什么角色」。
- 课堂案例提到父母爻持世、父母爻发动化官鬼回头生等结构，老师据此讨论公司、组织、公家业务或长期辛劳经营等含义。
- 父母爻在相关例子中还被联系到手续、组织、长期投入和辛苦经营；不能把父母持世简单等同于亏损。
- 还要看世爻自身力量、动爻变化及回头生克，不能只因财爻出现或不出现就下结论。
- 合伙关系和求财结果应分开核对；「赚公家的钱」等具体解释依赖原卦和课堂语境，不能推广成通则。

## 5. 健康问答：保留为课内案例，不转成医疗规则

课程中段及后段出现身体病情、老年人健康等讨论。老师提到疾病类问题需要结合所问主体、世爻、官鬼及动爻变化等信息，并提醒学习者不要轻易替别人下结论或承诺能够治病。

本节只记录课程确有健康问答这一事实。ASR 对病名、爻位、变卦、时间点和关键术语识别错误较多，不整理疾病预测公式，不据此推断病情严重程度、寿命或治疗结果。现实健康问题应由合格医疗人员评估。

## 6. 投资案例：不要轻率给方向

转录中有同学询问是否可以投资。老师提醒：

- 投资问题应围绕财务结果和风险分析，不要只看某个单一爻象。
- 要检查财爻、子孙、兄弟及世应关系，并比较动爻是否真正形成有效作用。
- 不能因看到某个有利组合，就忽略兄弟发动、财爻受损或世爻承受能力不足等因素。
- 老师提醒学习者谨慎给他人投资建议；能力不足或信息不完整时，宁可说明无法判断，也不要轻率引导他人承担风险。

具体投资卦的卦名、爻位及最后判断等待 HTML 卦盘或更清晰原始资料核对。

## 7. 婚姻案例：综合案例中的一个主题

课程后段有女性婚姻案例。转录中可辨认老师提及官鬼、兄弟及多重信息，但案例盘面和完整判断过程不充分。因此本课仅登记「包含婚姻案例」，不把残缺转写补成婚姻规则，也不与第十四课婚姻专题笔记混为一谈。

## 8. 结尾总结：老师强调的学习原则

结尾老师对综合断卦作了总结，可辨认的重点包括：

1. **世爻任何时候都不能忽略，首先检查世爻是否受伤。**不能只看用神而不管求测者自身状态。
2. **问什么事情，先抓对应的用神。**先确定问事目标，再检查对应六亲及其状态。
3. 老师提出，用神不上卦时，事情通常较难成；转录中出现「百分之八十」的说法。此处保留为课堂提醒，不把比例转成程序概率，也不视为无例外的绝对规则。
4. 世爻或用神伏藏、自身力量不足时，事情可能需要付出更多辛苦和代价；具体仍要结合伏神、飞神及全卦。
5. 应期要结合主事爻及用神相关线索。由于这段转录有错识，不在此补成完整应期算法。
6. 学习六爻要多看案例、多反馈、多验证；面对复杂卦例不要轻易给现实人物或事件下确定定义。
