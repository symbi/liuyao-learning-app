# 项目背景与范围

## 1. 项目是什么

这是一个以六爻课程学习为基础的网页项目。学习者可以输入六次摇卦结果，查看本卦、动爻、变卦以及后续排盘步骤。重点是**把规则讲清楚、让结果可核对**，而不是仅输出结论。

## 2. 使用场景

- 学完课程后整理知识点与术语。
- 通过输入摇卦结果练习排卦。
- 回看每个计算步骤使用了什么规则、依据来自哪里。
- 用课程案例测试规则是否实现正确。
- 后续逐步加入练习题和案例复盘。

## 3. 术语约定

- **摇卦 / 摇盘**：用三枚硬币连续摇六次，记录每次结果。
- **排卦 / 排盘**：根据六次结果计算并展示卦象与相关信息。
- **初爻到上爻**：六次输入在界面和数据中必须明确其顺序。
- **本卦、变卦、动爻**：作为首个 MVP 的核心展示内容。

如果课程资料对术语有更具体的定义，应以课程资料为准，并更新本文件。

## 4. 当前已知的资料状态

项目已有的资料线索（需要从用户自己的文件夹逐步导入或核对）包括：

- LY001-六爻课程重点笔记.md
- 六爻术语表-v0.1.csv
- Pasted text(2).txt（可能是转录文本候选，需要检查内容与完整性）
- 第三课 v0.3：分段转录、AI 笔记、机器可读规则、计算案例及术语修订。
- 第四课：目前只有课后回忆笔记，没有可用的完整转录稿；不要假设它等同于完整课堂记录。

这些是先前整理过程中提到的文件名和资料状态，并不表示这些文件已经提交到本仓库。导入前要检查文件是否存在、内容是否完整，以及是否适合公开。

## 5. 设计原则

1. 规则应当有稳定的 ID、明确的输入和输出。
2. 每个排盘结果都应尽可能追溯到规则和来源。
3. 不确定的内容必须显示为待核实，而不是由程序默默猜测。
4. 课程讲解、外部资料、模型推断分别标记。
5. 计算逻辑与网页展示分离。
6. 先实现最小闭环，再逐步增加复杂规则。

## 6. 暂不纳入首版

- 自动给出确定性命运判断或保证性预测。
- 未核实规则的自动推断。
- 账号体系、云端数据库、付费功能。
- 未经确认的课程原始录音、完整转录稿或受版权限制教材的公开发布。
