# L14-TAI-001：胎爻与子孙爻的取法存在待核实差异

- **状态：** 有分歧
- **来源：** 第十四课 ASR 转录，第 3 段
- **课程摘要：** 老师讨论胎爻的不同推法，并表达了以子孙爻作为较通用观察标准的倾向；但地支公式与不同方法的适用范围没有识别完整。
- **外部差异：** 《卜筮正宗·产育》把子孙与胎爻分开讨论，并将“是否有孕”另列为以胎爻为主的判断。见第十四课外部参考。
- **待核实：** 子孙爻作为求子用神与胎爻作为是否怀孕的观察是否分别适用于不同问题，还是流派差异。
- **实现要求：** 数据模型中分开保存“子孙爻”和“胎爻”；规则未核清前不自动计算胎爻或判定有孕无孕。
