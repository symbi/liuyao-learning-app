# L09-SHIYING-001：世应关系比较具体的两条爻

- **状态：** 核对中
- **来源：** 第九课 ASR 转录，第 2 段
- **课程摘要：** 老师提醒，世应关系要看具体世爻与应爻的爻位和五行，不是拿上卦、下卦直接代替世应。
- **重要区分：** 卦整体是否六冲/六合，与世爻和应爻两条具体爻之间是否比和、生、克、冲、合，是不同层次；可以同时存在，不应混作一项。
- **课程倾向：** 比和、相合通常较和顺；相冲、相克通常较不利。老师表示后续疾病、婚姻章节还会详讲，当前不把这些倾向写成无条件吉凶规则。
- **实现要求：** 分别保存卦级六冲/六合属性及世应两条爻之间的关系。
