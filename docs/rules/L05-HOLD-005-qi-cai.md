# L05-HOLD-005：妻财持世

- **状态：** 课程有明确讲解；部分动变取象待核对
- **来源：** 第五课原始 ASR 转录，第 4–5 段
- **规则摘要（课程归纳）：** 妻财与钱财、财运有关；课程提到男方问婚姻时，妻财也可作为用神。
