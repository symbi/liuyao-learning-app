# L14-USE-001：婚姻用神必须按求测者与所问对象关系取用

- **状态：** 核对中
- **来源：** 第十四课 ASR 转录，第 1–2 段
- **课程摘要：** 本人男问女婚通常以妻财观察女方；本人女问男婚通常以官鬼观察男方。父母替子女问婚、兄弟姐妹替兄弟姐妹问婚，不能直接照搬本人自占的财官规则。
- **外部对照：** 《卜筮正宗》辟《易林补遗》婚姻嫁娶之谬，也按自占/代占与具体亲属关系区分用神，见第十四课外部参考。
- **边界：** 复杂姻亲称谓和代占例子受 ASR 影响，未确认前不建立自动映射表。
- **实现要求：** 记录求测者身份、婚姻对象身份及亲属关系后再取用；不能仅凭男女决定所有婚姻用神。
