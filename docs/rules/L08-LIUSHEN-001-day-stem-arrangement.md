# L08-LIUSHEN-001：按日干自下而上排六神

- **状态：** 课程明确讲解；外部基础资料交叉核对
- **来源：** 第八课课程转录，第 1 段
- **课程内容：** 六神应从初爻向上爻排列，按起卦日的日干确定初爻起点。
- **起例：** 甲乙起青龙；丙丁起朱雀；戊日起勾陈；己日起螣蛇；庚辛起白虎；壬癸起玄武。
- **固定顺序：** 青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武，循环轮排。
- **示例：** 甲乙日初爻青龙、二爻朱雀、三爻勾陈、四爻螣蛇、五爻白虎、上爻玄武。
- **待核对：** 转录中某个“寅月/日”的提问可能识别错误；不改写成课程的确定原话。
- **实现要求：** 输入必须包含起卦日干；程序按初爻至上爻生成六项。不得用月支直接决定六神起点。
