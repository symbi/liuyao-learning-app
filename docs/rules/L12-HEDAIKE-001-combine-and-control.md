# L12-HEDAIKE-001：合中带克要比较双方力量

- **状态：** 核对中
- **来源：** 第十二课 ASR 转录，第 2–4 段
- **课程摘要：** 子丑合同时存在丑土克子水，卯戌合同样存在卯木克戌土。老师强调不能只看到六合就断为合好，或只看到五行相克就忽略合；应结合双方旺衰及日月、动爻的生扶克制判断哪种作用占主导。
- **适用线索：** 若被克方旺相且有日月或其他动爻生扶，克方力量不足时，课程倾向于偏合论；若克方得令有力、被克方休囚又受制，则更应重视克。
- **边界：** 子月课堂练习的 A/B/C 选项和完整爻支识别不清，不固化选项答案。
- **外部对照：** 《卜筮正宗·合中带克论》有相近的力量比较方法，见第十二课外部参考。
- **实现要求：** 对同一关系并列保存合与克，不得只输出单一“六合”标签；优先展示证据和不确定性。
