# L05-HOLD-002：父母持世

- **状态：** 课程有明确讲解；条件与适用边界继续核对
- **来源：** 第五课原始 ASR 转录，第 3 段及案例 A
- **规则摘要（课程归纳）：** 父母持世常与学业、功名、文书、证件、贵人/支持等取象联系；课程也提到操劳、进展较慢等可能性。
- **条件：** 结合具体问题判断父母爻所代表的对象；不把父母持世直接等同于一切顺利；父母爻力量强不自动证明某个结果成功。
- **课程特别提醒：** 求子时父母持世可能不利；案例 A 中父母力量强，但老师仍判断升职未成功，并讨论官鬼发动生父母等关系。
- **边界：** 何时代表贵人、文书或阻滞，需要更多课堂案例。
