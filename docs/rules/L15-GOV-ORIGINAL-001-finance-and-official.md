# L15-GOV-ORIGINAL-001：财爻与求官的辅助关系

- 课次：第十五课
- 状态：核对中
- 来源：第十五课 ASR，约 0–10 分钟；外部对照见《增删卜易·序》

## 规则摘要

老师讲到“财生官”：在已有官位/职位、进一步求升迁的语境中，财爻可作为生扶官鬼的原神或辅助观察对象。

## 课堂边界

老师特意区分初入官场/初入职场与已有职位后求升迁，提醒不能将两类问题都机械地以财爻作为主判断对象。ASR 对“初入时是否看财”“财爻旺相、休囚、发动、受日月冲时的具体断语”识别不清。

## 实现要求

- 求官始终先显示官鬼；
- 财爻作为相关辅助关系显示，不自动取代官鬼；
- 区分首次求职/进入组织与在职升迁；
- 未取得清晰例盘前，不实现“财旺必升”“财弱必不成”等规则。
