# L12-DONG-001：动爻关系不能因用神旺相而忽略

- **状态：** 核对中
- **来源：** 第十二课 ASR 转录，第 1–3 段
- **课程摘要：** 老师反复用“动必有因”提醒：发动之爻代表正在发挥作用的关系。即使用神当前旺相，仍须检查是否被卦中动爻克伤；反之，休囚用神若得发动原神生扶，也不能只按当前弱势下结论。
- **适用线索：** 逐条追踪动爻与用神、原神、忌神之间的生克关系，并区分“当前状态”和“动变后续影响”。
- **边界：** 该原则不表示任何动爻都一定能制成，也不表示原神发动就保证事情成功；仍须检查力量、合冲和受制条件。
- **实现要求：** 对动爻保存发动状态、关系对象和作用方向；不要把动爻简化为固定吉凶标记。
