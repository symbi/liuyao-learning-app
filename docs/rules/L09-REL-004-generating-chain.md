# L09-REL-004：多爻发动时追踪连续相生与贪生忘克

- **状态：** 核对中
- **来源：** 第九课 ASR 转录，第 3 段
- **课程摘要：** 老师用“兄弟爻发动生子孙爻，子孙爻再生妻财爻”的结构讲解接续相生，并用“贪生忘克”说明不能只停留在兄弟爻通常克财这一层。
- **分析步骤：** 列出发动爻 → 记录其生克目标 → 继续追踪受生爻是否再作用于其他关键爻 → 确认力量最终帮助或伤害的是用神、原神还是忌神。
- **限制：** 课堂比较的两个项目例子没有完整卦盘；不将其变成固定吉凶测试样本。“贪生忘克”不是凡见相生就忽略相克。
- **实现要求：** 以有向关系链保留每一步，不把多个生克关系算术抵消成一个分数。
