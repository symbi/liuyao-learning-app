# L12-HEDAIKE-002：合作求财需区分财爻与兄弟爻的作用

- **状态：** 待核实
- **来源：** 第十二课 ASR 转录，第 2–3 段
- **课程摘要：** 老师以子水财爻化丑土兄弟为例，讨论子丑合与丑土克子水并存时，究竟偏向合作还是劫财。还提醒要检查兄弟发动、财爻强弱，以及兄弟→子孙→妻财的连续相生关系。
- **适用线索：** 求财问题必须先区分个人求财与合伙求财，再逐项检查财爻、兄弟爻、原神及动变。
- **待核实：** 例盘、每一爻的具体地支六亲和老师最后断语不完整；不能把“兄弟动必劫财”或“有合便能合作”写成绝对规则。
- **实现要求：** App 先展示财爻与兄弟爻关系、合克并存和连续相生链；未具备完整输入时不自动输出合作/劫财结论。
