# L10-MOONBREAK-001：月破须结合爻自身旺衰和动变判断

- **状态：** 核对中
- **来源：** 第十课 ASR 转录，第 1–3 段
- **课程摘要：** 老师以求财例讨论用神逢月冲（月破）时，强调不能只见“月破”就断定爻永久失效；需要继续看本爻旺衰、是否发动、变爻、原神及日月扶助。
- **时间线索：** 当下受月令压制，与后续月份是否得到生扶可能不同。
- **限制：** 午火财爻、子月、寅卯月等案例细节 ASR 有错，不能简化为“出月必好”或“旺爻绝不怕月破”。
- **实现要求：** 同时保存月破状态、爻强弱、动静、动变、日辰和出月/填实条件；禁止月破=永久无用的单值判定。
