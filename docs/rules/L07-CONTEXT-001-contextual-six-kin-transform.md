# L07-CONTEXT-001：六亲化爻需结合问事语境

- **状态：** 核对中
- **来源：** 第七课 ASR 转录，第 1–4 段
- **课程线索：** 老师逐步讨论官鬼、父母、兄弟、子孙、妻财发动并化出不同六亲的意义，同时反复提醒不能脱离问事语境。
- **可辨认的例子线索：**
  - 官鬼化父母：在某些问题中关联文书、合同、证件等。
  - 官鬼化妻财：课程在某些年度/健康问题语境中提醒关注身体。
  - 官鬼相关变化不能直接推断儿童失踪、死亡或重大灾祸；要先了解问卦者和现实问题。
  - 妻财化兄弟在求财语境下可能提示钱财损耗。
- **限制：** ASR 无法清晰保留完整条件和所有规则；上述仅作课程线索，不构成通用断语。
- **实现要求：** 每个规则应标注“问事类别、原爻六亲、变爻六亲、五行关系、日月/旺衰、限制条件”。
