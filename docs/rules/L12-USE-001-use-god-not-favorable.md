# L12-USE-001：用神是所问对象，不等于喜神

- **状态：** 核对中
- **来源：** 第十二课 ASR 转录，第 1–2 段
- **课程摘要：** 老师明确提醒，用神不必然等于求测者喜欢或希望其增强的对象。用神首先对应本次问题的目标；不同问题中，同一六亲可能代表需要观察的对象或障碍。
- **适用线索：** 问病、问官司、问财、问工作等场景，需要先弄清所问对象，再解释它受生、受克、逢合或逢冲的意义。
- **边界：** 长辈健康例子的具体用神角色受到 ASR 影响；不从该例提取医学诊断或一概适用的疾病规则。
- **实现要求：** 用神字段应绑定占问目标及其语义，不得给用神默认“吉”或“喜”的标签。
