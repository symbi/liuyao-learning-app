# L06-DONG-001：动爻数量与分析复杂度

- **状态：** 核对中
- **来源：** 第六课（暂定）ASR 转录，第 1 段
- **课程线索：** 老师指出，动爻越多，需要分析的爻际关系通常越多，卦的解释更复杂；一爻发动时可更集中地检查该爻及其变爻。
- **不等于：** 动爻越少就一定更准、动爻越多就一定不吉。
- **条件：** 仍需识别用神、世应、发动六亲、变爻与其他爻的关系。
- **待核对：** 课程一处似乎暂时把日辰、月建放在分析范围之外，但相关语句 ASR 有冲突；不能将其设为永久的规则限制。
- **实现要求：** 作为解释流程提示，不做吉凶计算，也不直接影响分数。
