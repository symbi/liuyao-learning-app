# L07-JINTUI-001：化进神与化退神

- **状态：** 核对中；外部来源存在组合表差异
- **来源：** 第七课 ASR 转录，第 1–3 段；外部参考见 `docs/references/lesson-07-external-sources.md`
- **课程线索：** 老师用同五行地支变化（如寅木化卯木）讲解化进，并将其用于讨论工作/发展等问题。
- **外部基础知识：** 《增删卜易》在线文本列举：进神为亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌；退神为子化亥、卯化寅、午化巳、酉化申、辰化丑、未化辰、戌化未。另一些现代来源还列“戌化丑”等组合，见外部参考文件。
- **重要区别：** 化进/化退是特定地支变化术语，不等于任意“爻变成另一个六亲”。化进也不无条件等于吉，化退也不无条件等于凶。
