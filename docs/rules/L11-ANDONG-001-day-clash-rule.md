# L11-ANDONG-001：本课以日辰冲静爻作为暗动线索

- **状态：** 有分歧
- **来源：** 第十一课 ASR 转录，第 1–3 段
- **课程摘要：** 老师明确把暗动与起卦日的日辰相冲联系起来，并表示本课采用的处理方式是：静爻只要与日辰相冲，就按暗动论，不再按旺相/休囚区分。
- **适用线索：** 老师特别说到用神和世爻被日辰冲时要识别暗动；暗动与月建冲不是同一个条件。
- **来源差异：** 《增删卜易·日辰章》《暗动章》常见文字区分旺相静爻日冲为暗动、休囚静爻日冲为日破。见第十一课外部参考。
- **实现要求：** 将课程判定策略与传统判定策略分开配置；不得静默混用。
