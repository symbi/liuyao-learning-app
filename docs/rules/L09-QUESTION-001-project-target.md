# L09-QUESTION-001：问自己的项目，不用外部事件代替

- **状态：** 核对中
- **来源：** 第九课 ASR 转录，第 2 段
- **课程摘要：** 若关心高铁开通是因为自己的项目可能因此启动，老师要求直接问自己的项目能不能做、能否实现预期收益，而不是把高铁开通本身当成自己的问题。
- **课程强调：** 外部事件发生不等于自己的项目必然成功；整体财运好也不代表每个具体项目都会赚钱，整体财运差也不代表每个项目都失败。
- **限制：** 本课没有提供足够完整的项目卦盘和通用用神表；妻财与子孙的关注点仅记录为课程线索。
- **实现要求：** UI/学习流程应区分年度整体趋势、个人财运、单个项目、外部依赖事件等不同问题，禁止互相替代。
