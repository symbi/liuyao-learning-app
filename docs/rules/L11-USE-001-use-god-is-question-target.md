# L11-USE-001：用神是问题目标，不等于固定的喜用神

- **状态：** 核对中
- **来源：** 第十一课 ASR 转录，第 1 段
- **课程摘要：** 老师提醒，六爻“用神”代表本次所问的人、事或对象，不等于八字意义上的“喜用神”，也不必然是所有情境下都希望增强的因素。
- **课堂例子：** 求官时官鬼可代表所求职位；问疾病或官司时官鬼可能代表需要处理的问题。相冲、相合是否有利，须先分清该爻代表的是目标还是障碍。
- **限制：** 疾病占中官鬼与世爻可能分别代表病和人，相关特殊例子受 ASR 影响，不补成固定口诀。
- **实现要求：** 保存问事类型、目标对象和爻所代表的具体对象；不得仅根据“用神被冲/被合”直接输出吉凶。
