# L15-REASK-001：长期事项以第一卦为总体参照，关键节点可再问

- 课次：第十五课
- 状态：核对中
- 来源：第十五课 ASR，约 25–35 分钟

## 规则摘要

老师不赞成把“一件事只能占一次”绝对化。对持续时间较长的事项，可以先用第一卦观察总体方向；之后若因第一卦采取行动、作出决定，事件发展到新的关键节点，可以再次起卦。

## 关键边界

后续卦不能把第一卦完全替代。老师说其个人实践中会把第一卦作为整个事件的总体参照，后续卦与第一卦综合参考。

## 实现要求

同一长期事项应关联保存首次卦和后续节点卦，并记录重问原因（现实变化、已采取行动、进入新阶段等）。不因单纯时间经过而鼓励重复起卦。
