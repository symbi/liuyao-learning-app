# L08-REL-002：追踪连续相生最终作用到哪里

- **状态：** 课程明确提出的方法论；具体案例关系待核对
- **来源：** 第八课课程转录，第 3 段
- **课程摘要：** 不能看到某爻“生”了另一爻，就直接判断为对问卦者有利；如果力量继续传递，最终可能作用到不利的对象。
- **分析步骤：** 标出发动爻 → 标出变爻与其作用 → 记录受生爻 → 检查受生爻是否继续生、克或泄其他关键爻 → 确认最终受益者/受损者是否为世爻、用神或忌神。
- **限制：** 课堂例子因 ASR 错误未能复原完整卦盘；本条只登记追踪链条的方法，不补成具体五行断语。
- **实现要求：** 以有向关系链保留每一步，不把连续生克压缩成“有生所以吉”。
