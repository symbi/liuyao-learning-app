# L13-SHIYING-001：流年年运以世爻为主要观察轴

- **状态：** 核对中
- **来源：** 第十三课 ASR 转录，第 1–2 段
- **课程摘要：** 老师反复强调流年卦先看世爻，世爻代表卦主/自己。世爻的旺衰、动静、受日月生扶或冲克，是年度整体判断的主要起点。
- **适用线索：** 先评估世爻，再进一步看财、官、父母、兄弟、子孙等六亲与具体事项的关系。
- **边界：** 世爻为主轴不意味着其他爻不重要，也不允许仅凭世爻一个条件断定全年每件事。
- **外部对照：** 《易冒·年运章第四十七》同样以世爻为年运本位；见第十三课外部参考。
- **实现要求：** 年运总览优先显示世爻状态和依据，之后再显示六亲分项。
