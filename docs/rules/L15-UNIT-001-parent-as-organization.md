# L15-UNIT-001：父母爻作为单位/组织的课堂线索

- 课次：第十五课
- 状态：核对中
- 来源：第十五课 ASR，约 10–20 分钟；关联第十课、第十三课父母爻资料

## 规则摘要

在询问“去某个单位/公司工作怎么样”的语境中，老师明确提到父母爻代表单位。课程还讨论父母与印、文书、资格、文章/文才等含义。

## 边界

“父母爻代表单位”是本课的应用线索，不可扩写成所有求职问法一律以父母为用神。正官/偏官、正印/偏印等词在本段与八字语境交织，ASR 不能可靠辨别。

## 实现要求

把“单位/组织”“岗位/职责”“收入/待遇”作为不同目标展示；父母、官鬼、妻财之间的关系分别列出，不合并成单一工作分数。
