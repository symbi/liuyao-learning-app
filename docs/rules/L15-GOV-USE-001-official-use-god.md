# L15-GOV-USE-001：求官/功名以官鬼爻为核心

- 课次：第十五课
- 状态：核对中
- 来源：第十五课 ASR，约 0–20 分钟；外部对照见《增删卜易·序》《用神章第八》

## 规则摘要

老师明确把求官、功名的主要观察对象放在官鬼爻。官鬼持世、官鬼有力，或官星发动生合世爻，均被课堂作为有利线索讨论。

## 必须同时检查

- 世爻自身旺衰及是否得日月扶助；
- 官鬼爻是否旺相、静动、旬空、月破；
- 动爻与官鬼、世爻的生克冲合；
- 官鬼是否化出其他六亲，以及变爻是否回头作用；
- 本次到底问求官、升迁、年度官运还是具体岗位。

## 适用边界

不得简化成“官鬼持世必然当官/升职”。本课明确指出，官鬼持世也可能出现在官司、健康压力等其他语境；必须先确认问事类型。多重官鬼也不能只凭数量断职位高低。
