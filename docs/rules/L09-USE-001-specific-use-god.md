# L09-USE-001：具体占问先确定对应的用神

- **状态：** 核对中
- **来源：** 第九课 ASR 转录，第 1–2 段
- **课程摘要：** 老师把“先找用神”放在具体事情断卦的第一步。用神由本次真正要问的对象/事项决定，不是一个固定爻位或固定六亲。
- **可辨认例子：** 由子女代父母问父母病情，课程明确以父母爻为用神；求官、官司、女性问丈夫等提到官鬼爻；求财/经营项目需看妻财，且还要看原神。
- **限制：** 姻亲、年度趋势与自身健康部分的术语及例子受 ASR 影响，尚不能建立完整取用表。
- **实现要求：** 先保存问事目标、求测者与目标的关系、时间范围；没有足够资料时不得自动猜测用神。
