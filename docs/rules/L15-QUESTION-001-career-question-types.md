# L15-QUESTION-001：职业问题必须区分目标类型

- 课次：第十五课
- 状态：核对中
- 来源：第十五课 ASR，约 0–30 分钟；与第七课、第十二课具体化问事原则相连

## 规则摘要

本课区分求官/功名、初次进入职场、体制外求职、原单位内部升迁、岗位调动、询问具体单位/公司，以及年度官运。它们关注的目标不同，不宜混用用神。

## 实现要求

起卦前明确：
- 求测的是录用、职位、升迁、调动、薪资、单位环境，还是年度总体趋势；
- 是体制内还是体制外；
- 是首次进入组织，还是已有职位后竞争晋升；
- 是否有明确的单位、岗位和时间范围。

信息不足时先提示澄清，不自动把所有工作问题映射为官鬼爻。
