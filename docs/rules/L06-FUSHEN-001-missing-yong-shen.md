# L06-FUSHEN-001：用神不现与伏神

- **状态：** 核对中（基础概念可外部交叉核对；课程中的具体示例待核对）
- **来源：** 第六课（暂定）ASR 转录，第 4 段
- **课程线索：** 老师讨论问事所需的六亲在本卦未出现时，应进一步按本卦所属卦宫查找对应的用神/伏神，而不是直接停止判断。
- **常见基础流程（外部参考，不作为课堂逐字内容）：**
  1. 明确所问事项与用神。
  2. 检查本卦明现六亲。
  3. 若用神不现，按所属卦宫的本宫全图查找缺失六亲作为伏神候选。
  4. 记录伏神所在爻位以及对应飞神，再核对生克关系。
- **待核对：** 转录中的“缺妻财/找伏神”例子混杂多个误识词，无法复现其完整卦盘；不同规则体系对用神多现、变爻与伏神的查找优先次序也可能不同。
- **实现要求：** 在排盘层先显示“用神未明现/伏神待查”，不要默默猜出一个伏神。
