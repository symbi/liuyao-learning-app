# L08-REL-001：明确“克身/生用”所针对的爻

- **状态：** 课程明确提醒；术语具体范围待后续核对
- **来源：** 第八课课程转录，第 2–3 段
- **课程提醒：** 不要把“身”不加区分地理解成任何一个固定爻位；讨论克身、生身或生用时，要说明关系最终针对哪个爻。
- **基本区分：** 世爻通常代表问卦者自身；用神代表当前问题的核心对象/事项。不同问事会选不同用神。
- **示例：** 求财时要看妻财用神；求官时通常观察官鬼用神；求文书/学业时可能观察父母用神。它们不因世爻位置而自动相同。
- **实现要求：** 每一条生克记录必须包含 source_line、target_line、relation_type，并标明 target 是世爻、用神或其他爻；不把“克身”写成一个没有目标的布尔值。
