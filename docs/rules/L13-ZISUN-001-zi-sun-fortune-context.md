# L13-ZISUN-001：子孙为福德解忧之神，须结合年龄和问事

- **状态：** 核对中
- **来源：** 第十三课 ASR 转录，第 2–3 段
- **课程摘要：** 老师把子孙称为福德之神、解忧之神。子孙有力可有解忧、轻松或生财等线索；子孙休囚无力且世爻受冲克，课程认为当事人可能较被动。
- **情境差异：** 年长者问生活安逸时，子孙可取福德、解忧之象；年轻人问功名/求官时，子孙克官鬼可能与目标相冲突；问子女时又需结合具体子女事项。
- **边界：** 不把子孙持世固定判为吉，也不依据年龄推断寿命、子女数量或健康。
- **实现要求：** 结合所问目标、年龄阶段（若用户提供）和具体六亲关系显示解释，不设置通用吉凶标签。
