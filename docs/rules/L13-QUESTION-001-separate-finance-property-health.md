# L13-QUESTION-001：年度总览与财、事业、健康等专项问题分层

- **状态：** 核对中
- **来源：** 第十三课 ASR 转录，第 1–3 段
- **课程摘要：** 年运卦可观察年度整体趋势，但具体投资、欠款、买卖房屋、合同或健康问题仍要明确单一目标并按事项判断。老师提醒不要用一个模糊年度问题代替每个具体事件的分析。
- **适用线索：** 财务、事业、健康、子女、房产等维度要看各自相关六亲，但解释必须回到本次所问的对象。
- **边界：** 本课不支持建立所有六亲在年度中固定不变的“吉凶字典”。
- **实现要求：** 先选择年度总览或具体事项；具体事项需写清目标和时间范围，不自动混合多个目标。
