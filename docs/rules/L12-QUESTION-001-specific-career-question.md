# L12-QUESTION-001：职业问题应落到具体岗位或事项

- **状态：** 核对中
- **来源：** 第十二课 ASR 转录，第 4–5 段
- **课程摘要：** 老师认为“我适合什么行业”范围太大，行业之间也可能交叉，难以形成明确判断目标；建议改问某一份具体工作、当前项目、一个工作机会或具体任务。
- **适用线索：** 提问时区分自己要判断的是收入、专业能力/名气、职位，还是工作环境和稳定性；这些不是同一个目标。
- **待核实：** 后续关于同事、同业、专业水平、名气与收入的六亲映射识别不完整，不据此建立自动取用神表。
- **实现要求：** 起卦前提示用户明确具体事件、所求结果和时间范围；对过宽问题提示拆分，而不是自动猜测行业用神。
