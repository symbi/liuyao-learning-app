# L14-MEJIAN-001：间爻可观察媒人或介绍渠道

- **状态：** 待核实
- **来源：** 第十四课 ASR 转录，第 2 段
- **课程摘要：** 老师在讨论认识对象途径时提到间爻/中间人，作为媒人、介绍人或关系连接者的线索。
- **适用线索：** 问缘分通过谁介绍、是否有中间人时，可以把间爻作为观察对象之一。
- **待核实：** 两间爻俱空、同动、受克及世用远近的具体规则没有清晰复原。
- **外部对照：** 《卜筮正宗·婚姻》也有“欲通媒妁，须论间爻”的论述，但直接占问媒人本人时用神另有区别。
- **实现要求：** 先显示间爻状态作为辅助线索，不自动判定认识渠道和媒人身份。
