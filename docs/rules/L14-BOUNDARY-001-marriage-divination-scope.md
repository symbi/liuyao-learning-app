# L14-BOUNDARY-001：婚姻占问要先判断是否适合起卦

- **状态：** 核对中
- **来源：** 第十四课 ASR 转录，第 1 段
- **课程摘要：** 老师区分已有对象/正在交往与未婚无对象的情况；对已有交往对象尤其家长替子女判断当前伴侣，表达了不鼓励随意起卦的态度。未婚无对象者可以围绕缘分、对象特点和认识途径提出问题。
- **边界：** 开头多处 ASR 识别不清，不把课堂倾向改成所有婚姻问题一律禁止。正式离婚诉讼、财产保全等属于不同问题类型，应按实际法律程序处理。
- **实现要求：** 起卦前确认单身/交往/已婚/离婚诉讼等关系状态及本次目标，不默认把所有婚恋困惑作为同一类占问。
