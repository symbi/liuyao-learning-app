# L12-WANGXIU-002：旺相爻仍可能受动爻克伤

- **状态：** 核对中
- **来源：** 第十二课 ASR 转录，第 1–2 段
- **课程摘要：** 旺相表示当前得令，并不代表不会受卦中动爻克制。老师以财爻受兄弟动爻克为例，提醒“当下无碍”不能等同于后续安全。
- **适用线索：** 先确认被克对象是否为本次用神，再检查克方是否发动、有力，以及月日是否提供生扶或制约。
- **边界：** “过后难逃”是课程中的时间性解释方向；没有明确应期和完整卦盘时，不可自动推算具体哪一天或哪一月发生。
- **实现要求：** 分开展示月令旺衰和动爻克制；当两者方向相反时同时保留，不允许旺相状态覆盖动爻关系。
