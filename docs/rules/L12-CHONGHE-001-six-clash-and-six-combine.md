# L12-CHONGHE-001：六冲与六合的变化要结合所问目标

- **状态：** 核对中
- **来源：** 第十二课 ASR 转录，第 3–4 段
- **课程摘要：** 老师反对把六冲、六合固定标记为吉或凶。六冲变六合，可表现为开始不顺、后来聚合；六合变六冲，可表现为起初顺利、后来散开。若所问之事本来希望冲散障碍，六冲的意义又可能不同。
- **适用线索：** 先明确所问事情需要稳定、合作、持续，还是需要解除、分开、冲散，再解释卦级冲合变化。
- **外部对照：** 《卜筮正宗·合处逢冲、冲中逢合论》也区分六合变六冲与六冲变六合的过程含义；《增删卜易·六冲章》强调仍须结合用神旺衰。
- **实现要求：** 仅显示卦级关系变化和所问目标，不对所有六冲/六合直接上固定吉凶颜色。
