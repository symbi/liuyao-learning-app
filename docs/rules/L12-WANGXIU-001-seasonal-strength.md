# L12-WANGXIU-001：旺相休囚的季节基础

- **状态：** 有分歧
- **来源：** 第十二课 ASR 转录，第 1 段
- **课程摘要：** 老师以当令为旺、当令五行所生为相；旺相视为有力量，休囚相对弱。课堂给出的基础表为春木旺火相、夏火旺土相、秋金旺水相、冬水旺木相；辰戌丑未四季月土旺金相。
- **适用线索：** 这是判断单爻力量的季节背景，需与本卦、日辰、月建及其他爻的生克关系共同分析。
- **来源差异：** 不同古籍对四季土、六月金及休/囚/死的分类存在不同表述。参见第十二课外部参考，不将某一表格当作所有流派唯一标准。
- **待核实：** 丑月金的力量要结合原局根气、墓库和其他生扶制约；本课例盘与个别关键词不清。
- **实现要求：** 季节旺衰作为独立信息显示；不要仅凭月支输出最终吉凶或单一强弱分数。
