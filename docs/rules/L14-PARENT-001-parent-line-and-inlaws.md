# L14-PARENT-001：婚姻卦中的父母爻与长辈姻亲关系

- **状态：** 核对中
- **来源：** 第十四课 ASR 转录，第 2 段
- **课程摘要：** 老师提醒父母爻在婚姻卦中还涉及双方长辈、婆媳、翁姑等关系；父母爻发动或与世用发生冲合克生时，需要单独观察。
- **边界：** 老师对父母爻是否必须安静、何种发动为不利的具体句子受到 ASR 影响，不将“父母动必凶”固化。
- **外部对照：** 《卜筮正宗·婚姻》亦有父母/官鬼发动与翁姑、妯娌关系的论述，见外部参考。
- **实现要求：** 婚姻问事中保留父母爻状态及其与世用、财官的关系；不得单凭父母爻动就判定长辈干涉。
