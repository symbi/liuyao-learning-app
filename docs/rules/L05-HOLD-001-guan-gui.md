# L05-HOLD-001：官鬼持世

- **状态：** 课程有明确讲解；条件与适用边界继续核对
- **来源：** 第五课原始 ASR 转录，第 2–3 段；案例 A
- **规则摘要（课程归纳）：** 官鬼持世表示官鬼所象征的力量处于世位。课程提到官职、功名、领导/权力，也提到疾病、官司、压力和财务损失等取象。
- **条件：** 先确认世爻位置与六亲装配无误；结合问事类型；检查子孙发动克官鬼，以及旬空、入墓、日月、其他动爻等因素。
- **课程强调：** 官鬼持世不等于升职必成；子孙爻发动克官鬼可能不利于求官。
- **边界：** 具体旺衰、入墓与动变判断需要其他课程规则支持。
- **测试案例：** 第五课案例 A 中老师最终判断未成功，但课堂承认有争议；缺少完整卦盘，不作为严格测试期望值。
