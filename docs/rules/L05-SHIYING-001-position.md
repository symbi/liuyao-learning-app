# L05-SHIYING-001：世应位置关系

- **状态：** 位置对应规则可由课程与公开参考资料交叉核对；世爻初始定位仍需独立规则
- **来源：** 第五课原始 ASR 转录，第 1 段；外部参考见下方
- **课程内容：** 先找世爻，应爻与世爻相隔两个爻位。
- **准确表述：** 六爻从下往上编号为初、二、三、四、五、上。世与应的爻位编号相差 3（按六爻循环配对）：初—四、二—五、三—上。
- **示例：** 若已知世爻在四爻，则应爻在初爻；若世爻在初爻，则应爻在四爻。
- **重要边界：** 此映射只负责“已知世爻后定位应爻”。它不能单独判断一个具体卦的世爻在哪里；还要先依八宫卦世次定位世爻。
- **课程解读：** 老师强调不应只把上卦和下卦直接等同于问卦者与对方，而应具体看世爻、应爻本身及五行关系。
