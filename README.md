# 六爻学习与排卦 Web App

一个以课程学习为基础、规则可追溯的六爻学习网页项目。目标不是直接给出无法解释的断语，而是帮助学习者输入六次摇卦结果，逐步展示本卦、动爻、变卦及排盘规则的计算过程。

> 项目状态：规划 / 初始脚手架。目前还没有可运行的网页实现。六爻规则以课程资料为准；未核实的规则会明确标记，不会静默补齐。

## 项目目标

- 用网页记录三枚硬币六次摇卦的结果。
- 按初爻到上爻的顺序展示六次结果。
- 生成并展示本卦、动爻与变卦。
- 对每一步计算给出可检查的解释，并标注采用的规则来源。
- 逐步扩展纳甲、六亲、世应、旬空、六冲六合等排盘内容。
- 把课程笔记转成结构化、可测试的规则与案例，辅助复习和练习。

## 仓库与数据边界

当前阶段不新建数据仓库，按现有项目分工：

- **本仓库（Public，Learning）**：放项目代码、项目文档、整理好的课程摘要、术语表、规则索引，以及老师课堂案例（包括卦例、老师原始解说和用户在 HTML 中选择的案例分类，如「求学」「求工作」）。
- **现有 raw 仓库（Private）**：继续存放原始课程录音、未经整理的转录稿、原始 PDF 和暂未整理的来源文件。整理后的课堂案例应归入本 Learning 仓库。
- **每日卦例**：当前只保存在 HTML 的浏览器本地存储，并通过 JSON 导入/导出备份；不提交到 Public Learning 仓库。未来再评估 Supabase 等数据库。

老师案例属于 Learning 学习资料，不需要另建一个 data repository。每日卦例则是另一类个人数据，未来是否使用独立数据库，等实际使用需求明确后再决定。

**安全提醒：** Public 仓库不要放密码、访问令牌、个人身份信息或不应公开的材料。

## MVP 计划

- 六次摇卦输入（每次记录三枚硬币的结果或花面数量）。
- 从初爻到上爻显示输入顺序。
- 展示每爻的阴阳与是否为动爻。
- 展示本卦与变卦。
- 显示计算步骤、规则 ID、规则状态和来源备注。
- 用经过人工核对的案例做自动测试。

具体硬币计数映射仍需与课程原始资料核实，见 [规则状态清单](docs/rules-status.md)。

## 建议的开发方式

在电脑上克隆仓库后，可用你熟悉的编程工具阅读这些文档并逐步实现。项目初期先不要把未经核实的规则写死在计算逻辑中；将规则数据与 UI 分开，并为每条规则添加测试。
