# 六爻学习与排卦 Web App

一个以课程学习为基础、规则可追溯的六爻学习网页项目。目标不是直接给出无法解释的断语，而是帮助学习者输入六次摇卦结果，逐步展示本卦、动爻、变卦及排盘规则的计算过程。

> 项目状态：规划 / 初始脚手架。目前还没有可运行的网页实现。六爻规则以课程资料为准；未核实的规则会明确标记，不会静默补齐。

## 项目目标

- 用网页记录三枚硬币六次摇卦的结果。
- 按初爻到上爻的顺序展示六次结果。
- 生成并展示本卦、动爻与变卦。
- 对每一步计算给出可检查的解释，并标注采用的规则来源。
- 逐步扩展纳甲、六亲、世应、旬空、六冲六合等排盘内容。
- 把课程笔记转成结构化、可测试的规则与案例，辅助复习和练习。

## 仓库分工：整理好的资料 vs. 原始资料

计划使用两个仓库：

- **本仓库（Public）**：放项目代码、项目文档、已经整理好的课程摘要、术语表、规则索引、核对后的案例、个人编写的 PDF/其他仓库总结，以及可公开分享的参考资料链接。
- **另一个仓库（Private，建议命名为 liuyao-learning-raw）**：放原始课程资料、未经整理的转录稿、原始 PDF、批量导出的文件，以及暂时还没判断如何归类的资料。

原始资料整理完成后，把适合复用的摘要、规则、术语和案例整理进本 Public 仓库。不要为了“先存进去”而把整个 Google Drive 一股脑直接提交到 Public 仓库。

**重要：** 将 Public 仓库以后改成 Private，不能保证撤回之前已经被他人克隆、分叉或缓存的内容。因此，先放入 Private raw 仓库、整理后再发布，是更稳妥的工作流。Public 仓库中仍然不要放密码、访问令牌、个人身份信息或不应公开的材料。

## MVP 计划

- 六次摇卦输入（每次记录三枚硬币的结果或花面数量）。
- 从初爻到上爻显示输入顺序。
- 展示每爻的阴阳与是否为动爻。
- 展示本卦与变卦。
- 显示计算步骤、规则 ID、规则状态和来源备注。
- 用经过人工核对的案例做自动测试。

具体硬币计数映射仍需与课程原始资料核实，见 [规则状态清单](docs/rules-status.md)。

## 建议的开发方式

在电脑上克隆仓库后，可用你熟悉的编程工具阅读这些文档并逐步实现。项目初期先不要把未经核实的规则写死在计算逻辑中；将规则数据与 UI 分开，并为每条规则添加测试。
