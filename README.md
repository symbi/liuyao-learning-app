# 六爻学习与排卦 Web App

一个以课程学习为基础、规则可追溯的六爻学习网页项目。目标不是直接给出无法解释的断语，而是帮助学习者输入六次摇卦结果，逐步展示本卦、动爻、变卦及排盘规则的计算过程。

> **项目状态：规划 / 初始脚手架。** 目前还没有可运行的网页实现。六爻规则以课程资料为准；未核实的规则会明确标记，不会静默补齐。

## 项目目标

- 用网页记录三枚硬币六次摇卦的结果。
- 按初爻到上爻的顺序展示六次结果。
- 生成并展示本卦、动爻与变卦。
- 对每一步计算给出可检查的解释，并标注采用的规则来源。
- 逐步扩展纳甲、六亲、世应、旬空、六冲六合等排盘内容。
- 把课程笔记转成结构化、可测试的规则与案例，辅助复习和练习。

## 设计原则

1. **课程优先**：课堂明确讲过的内容，以可定位的课程笔记或原始资料为依据。
2. **标注不确定性**：未经确认的规则和案例不能当成定论。
3. **解释计算过程**：显示输入、规则、计算结果，而不只显示最终排盘。
4. **区分来源**：课堂规则、外部资料、程序推断分别记录。
5. **先做小而可验证的版本**：先完成六次输入和本卦 / 变卦，再扩展复杂排盘。
6. **保护学习资料**：本仓库为公开仓库。不要未经确认就上传课程录音、完整转录稿、付费教材或其他可能受版权限制的材料。

## 规划中的 MVP

- 六次摇卦输入（每次记录三枚硬币的结果或花面数量）。
- 从初爻到上爻显示输入顺序。
- 展示每爻的阴阳与是否为动爻。
- 展示本卦与变卦。
- 显示计算步骤、规则 ID、规则状态和来源备注。
- 用经过人工核对的案例做自动测试。

具体硬币计数映射仍需与课程原始资料核实，见 [规则状态清单](docs/rules-status.md)。

## 建议的开发方式

在电脑上克隆仓库后，可用你熟悉的编程工具阅读这些文档并逐步实现。项目初期先不要把未经核实的规则写死在计算逻辑中；将规则数据与 UI 分开，并为每条规则添加测试。
