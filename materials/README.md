# 学习资料目录说明

这个目录用于放置**适合公开**且对项目开发有帮助的资料索引、个人编写的摘要或明确允许公开的学习材料。

## 建议放入

- 个人编写的术语表与规则索引（确认可以公开后）
- 自己编写的测试案例和数据格式说明
- 公开许可允许再分发的参考资料链接
- 不含课程原文的资料目录与处理状态

## 暂时不要直接放入

- 课程录音或视频
- 完整课堂转录稿
- 付费教材的扫描件或大段原文
- 含有个人信息、账号信息或其他不适合公开的内容

“内容不涉及秘密”与“可以公开再分发”并不是同一回事。对拿不准的资料，先留在本地私人目录，公开仓库里只记录文件名、来源和处理状态。

## 推荐的文件命名

- glossary-public.csv：适合公开的术语表
- rules-index.md：规则索引，不复制大段课程原文
- cases/：经过核对、适合公开的测试案例
- sources.md：公开来源与许可备注

当前目录说明不代表已有课程文件已上传。导入资料时应逐一确认。
