# 学习资料目录说明

本目录属于 **Public 的整理资料仓库**，用于放置整理完成、方便检索和复用的学习材料。原始资料与暂时未整理的文件应先放在独立的 Private raw-data 仓库中。

## 建议放入本仓库（Public）

- 自己编写、整理好的课程摘要与复习笔记
- 术语表、规则索引和规则状态说明
- 已核对、带有来源说明的计算案例和测试数据
- 自己整理的其他仓库摘要
- 自己编写的 PDF 总结或其他可复用学习文档
- 公开许可允许分享的参考资料链接

## 建议放入 Private raw-data 仓库

建议另建一个 Private 仓库，例如 liuyao-learning-raw，用于保存：

- Google Drive 导出的原始文件和批量备份
- 尚未整理的课程笔记、转录稿和原始 PDF
- 待分类、待核对的资料
- 后续需要回查的原始版本

Private raw-data 仓库是原始资料的归档区；本 Public 仓库是经过整理的知识库与应用项目。整理完成后，将有用的摘要、规则、术语和案例复制或改写到本仓库，并保留来源标记。

## 推荐的整理流程

1. 从 Google Drive 导出或下载文件。
2. 先放入 Private raw-data 仓库或本地原始资料目录。
3. 检查文件名、内容完整性、重复项与来源。
4. 用 AI 帮助提取摘要、术语、规则和案例；对不确定内容保留待核实标记。
5. 将整理结果保存到本 Public 仓库，并记录原始文件名或来源路径。
6. 不要在整理时丢掉原始资料中的不确定性，也不要把 AI 推断写成课堂原话。

## 公开仓库注意事项

Public 仓库不是私密备份。即使之后把仓库改为 Private，也无法保证撤回已经被克隆、分叉或缓存的内容。不要提交密码、访问令牌、个人身份信息或明确不应公开的内容。

当前目录说明不代表 Google Drive 的文件已经被访问或导入；需要先取得文件本身，再逐批整理。
