# 课堂案例

这里保存从课程中单独整理出来的老师课堂案例。课堂笔记仍放在 `docs/lessons/`，本目录不替代课程笔记。

每个案例只保留必要信息：

- `recordType`: 固定为 `class-case`
- `sourceLesson`: 来自哪一课
- `category`: 用户在 HTML 中选择的案例分类
- `tagOrRealQuestion`: 可选的 tag，或当事人真正提出的问题
- `casting`: 有可靠资料时才保存的卦盘快照
- `teacherAnalysis`: 老师对案例的原始解说

不按 Category 建文件夹。Category 是案例数据字段，HTML 案例列表按它筛选即可。

课程笔记中提及但缺少完整卦盘或老师分析的内容，先留在对应课程的「案例线索」部分，不要自动补成完整案例。老师原始转录仍遵循现有 raw 资料归档方式。
