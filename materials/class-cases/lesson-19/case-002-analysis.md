### 盘面中与课堂 Memo 对应的结构

1. **兄弟持世：** 三爻申金为兄弟，正是 Memo 和 ASR 中“兄弟持世莫求财”这一讨论线索。
2. **本卦不见明现妻财：** 六条明爻的六亲为父母、官鬼、兄弟、子孙、兄弟、父母，没有妻财；但二爻官鬼午火下方另有一项人工标注的伏藏六亲妻财。原记录没有填伏神地支，因此本档案不补造地支。
3. **初爻父母动化妻财：** 初爻辰土父母明动，变为卯木妻财；保存快照标记变爻卯木旬空。按五行关系，卯木克辰土，可描述为财回头克父母。此项属于 HTML 盘面和规则复算，不能声称 ASR 已逐字讲清。
4. **月建见财与变爻旬空要分开：** 月柱乙卯，卯木对兑宫金为妻财；初爻变支也为卯木，保存快照标记该变爻旬空。不能把月建本身和具体变爻的旬空状态混为一谈。
5. **酉金月破：** 五爻酉金为兄弟，受卯月冲，保存快照标记为月破。
6. 二爻午火受日支子水冲，但本条记录未将它标记为暗动；这里保留保存记录的动静状态，不自行增添暗动。
