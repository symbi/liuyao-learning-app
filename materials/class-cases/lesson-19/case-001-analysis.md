## 4. 伏神完整推算：官鬼亥水

### 第一步：确定卦宫五行和目标六亲

本卦天水讼属离宫，离宫属火。此题问体制内工作调动，以官鬼为用神。克火者为水，因此**离宫的官鬼属水**。

### 第二步：检查本卦六爻

本卦六条明爻的六亲为：

`父母、子孙、兄弟、兄弟、妻财、子孙`

没有官鬼，所以官鬼用神没有在本卦六爻明现，需要继续查伏神。

### 第三步：回到离宫本宫纯卦

离宫本宫纯卦为**离为火**。按初爻到上爻的纳甲顺序：

`卯、丑、亥、酉、未、巳`

再按离宫火确定每一爻六亲：

| 爻位 | 离为火纳甲 | 五行 | 六亲 |
|---|---|---|---|
| 初爻 | 卯 | 木 | 父母 |
| 二爻 | 丑 | 土 | 子孙 |
| 三爻 | 亥 | 水 | **官鬼** |
| 四爻 | 酉 | 金 | 妻财 |
| 五爻 | 未 | 土 | 子孙 |
| 上爻 | 巳 | 火 | 兄弟 |

所以目标用神官鬼出现在离为火的**第三爻，纳甲亥水**。

### 第四步：放回实际本卦同一爻位

离为火第三爻找到的是官鬼亥水；回到天水讼的第三爻，其原有飞神为兄弟午火。因此：

- **伏神：官鬼亥水**
- **飞神：兄弟午火**
- **位置：三爻**
- **五行关系：亥水克午火，即伏神克飞神（伏克飞）**

这里要分清三种资料状态：

1. HTML 当前保存的人工标注：`hiddenRelation = "官鬼"`。
2. 按本宫纯卦纳甲复算出来的伏神完整信息：`官鬼亥水`。
3. 第十九课 ASR 可辨认的老师讲法：官鬼伏在发动的兄弟爻下面。ASR 没有可靠识别“亥水”这个地支。

所以，**官鬼亥水是按课堂方法和已保存卦盘推算的结果，不是 HTML 原字段，也不是 ASR 逐字识别结果。**

## 5. 老师在第十九课中的分析脉络

以下是根据第十九课第 1 段开头 ASR 归纳的老师讲解，不是逐字引用：

1. **先明确问题。** 问的是体制内一个具体岗位的调动能否成功，目标岗位相对明确。
2. **看世爻和应爻。** 世爻为兄弟，老师将它看作求测者一方；应爻为父母，父母爻与岗位、领导或支持因素有关。课堂笔记补充了“副职领导帮助”的理解；ASR 对这一小段识别不稳。
3. **看两重兄弟爻的竞争。** 老师将两重兄弟爻分成求测者一方与另一位竞争者。四爻兄弟午火持世，三爻另一个兄弟午火代表竞争的一方。
4. **先看到有利条件。** 甲寅月、乙卯日的木气生火；世爻兄弟午火得月日生扶，父母爻也得到月日支持。因此老师先提到调动有希望的一面。
5. **再比较动静和动变。** 另一个兄弟爻（三爻）发动并化妻财酉金；世爻（四爻）静而不动。老师据此认为竞争者一方更占优势。
6. **看用神不现。** 官鬼在本卦六爻中没有明现，老师指出官鬼伏在发动的兄弟爻下面。按纳甲规则进一步复算，伏神为官鬼亥水。
7. **结论和建议。** 老师最后倾向认为成功机会很小，建议不要在这件事上投入过多精力。

### 老师结论强度的保存差异

HTML 原记录的 `caseConclusion` 写的是“工作调动不能成功，有竞争者，竞争不过”。但 ASR 中老师反复强调的更接近“成功率很小”“不宜在这上面投入太多精力”，并非绝对宣布零可能。

本复盘采用更贴近 ASR 的表述：**成功机会很小，竞争者一方更占优势；可以适度努力，但不宜投入过多精力。** 原 HTML 记录暂不擅自改写，待用户确认是否同步调整。

## 6. 本案例学习重点

- 用神要先根据问事确定。问工作调动/求官，先抓官鬼；不能只看父母或兄弟。
- 用神不在本卦六爻明现时，按卦宫五行确定六亲，再回本宫纯卦逐爻查纳甲，找到伏神地支。
- 伏神必须落到与实际卦同一爻位，不能只知道“有官鬼伏藏”而不找具体哪一爻、哪一个地支。
- 两个同六亲爻可能代表不同角色。这里一个兄弟持世代表求测者，另一个兄弟发动代表竞争者；不能看到兄弟就笼统断竞争。
- 世爻得月日生扶是有利信息，但不能因此忽略另一个竞争者兄弟爻发动化财。
- 伏神克飞神是五行关系记录，不等于单凭这一点就能断成败；仍要结合用神旺衰、月建日辰、动变和老师整卦判断。
